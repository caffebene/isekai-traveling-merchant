# 开源道具试用批次

本批次曾用于和此前生成图做运行时效果对比，目前未启用。当前运行时使用 `candidates/generated` 中的 `ordinary-fantasy-v2` 普通异世界批次；如需再次试用，可修改 `scripts/item_art.gd` 顶部的 `ITEM_TEXTURES` 映射。

## 来源与许可

- MELLE 的 [2D Fantasy Collection](https://opengameart.org/content/2d-fantasy-collection) 及其 [Fantasy Sword Set](https://opengameart.org/content/fantasy-sword-set)、[Fantasy Crystal Set](https://opengameart.org/content/fantasy-crystal-set)、[Fantasy Potion Set](https://opengameart.org/content/fantasy-potion-set)、[Fantasy Magic Set](https://opengameart.org/content/fantasy-magic-set) 和 [Resource Pack 1](https://opengameart.org/content/resource-pack-1) 页面标注为 CC0。
- `raw/melle_resource_pack_1.png` 是 Resource Pack 1 原始图集；`melle_berry.png`、`melle_steak_ffmpeg.png`、`melle_ore_blue_ffmpeg.png` 是从图集中裁出的单项候选，保留原图集以便追溯。

| 道具 | 当前试用素材 |
|---|---|
| 小背包、烹饪锅 | Fantasy Magic Set |
| 旅人长剑、强化长剑 | Fantasy Sword Set |
| 月光草 | Fantasy Magic Set |
