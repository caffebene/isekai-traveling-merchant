# 道具资源

全局规则见 [整体视觉与UI规范](../../docs/game-design/整体视觉与UI规范.md)。当前运行映射以 `scripts/item_art.gd` 为准；工作台、炼药器与两种燃料使用 `workbench/*-unified.png`。生成提示与源路径见 `unified-generation.json`。旧同名机器、材料以及候选里的炉子/炼药器不参与运行。

本目录是经营页与探索页共用的独立道具 PNG。所有资源均为 RGBA，按未旋转占格尺寸导出；运行时由 scripts/item_art.gd 根据物品占格绘制，按 R 旋转时只旋转绘制矩形，不改变物品碰撞尺寸规则。

## 处理规则

- 普通道具生成图要求真实透明背景、单个物品、清晰剪影、稳定线稿、大色块、成组阴影和少量高光；道具主体采用普通异世界的自然手工材质，不使用科技、科幻、赛博朋克或现代工业设计。肉类统一为无骨肉块，肉排只表现肉排本身。炼药器和工作台使用 `docs/game-design/道具生成提示词.md` 的都市工业设备分支，采用完全正面正交视角。
- 处理时忽略 alpha 小于 12 的近透明雾边，按目标占格比例放入 96 px/格的透明画布。
- 物品本体最大填充画布 94%，保留约 6% 安全边距，避免贴边和拖动时裁切。
- 运行时由 `scripts/item_art.gd` 统一绘制约 1.5 px 的深黑外轮廓，经营场景与探索场景保持一致；描边不烘焙进源 PNG，避免重复叠加。
- 原始生成图保留在 Codex generated_images；项目实际引用的是本目录下的处理后 PNG。

生成提示词统一见 `docs/game-design/道具生成提示词.md`；生成记录与源文件映射见 `generation.json`。
