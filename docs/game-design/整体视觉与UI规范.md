# 《异世界旅商》整体视觉与 UI 规范

版本：`merchant-ledger-v2` · 2026-10-02 · 当前唯一全局风格依据。

新界面、组件和美术提示词先读取本文件。用户提供的 [物品信息卡参考](references/物品信息卡参考.jpg) 为当前 UI 方向；旧《绝区零》方向、暖白标题条、切角、橙色操作块与双斜线均已退出当前规范。历史文件只用于追溯，不能覆盖本文件。

## 1. 项目定位

《异世界旅商》，桌面 Godot 游戏。1600×900 逻辑画布、1440×810 窗口、等比缩放。玩法为实体柜台交易、空间库存、加工、行情、旅行、改装与探索。保留物品身份、占格、数值和核心操作。

## 2. 视觉关键词

古典旅商账册、深色底板、暖棕边框、金色标题、绿色属性。

## 3. 整体视觉方向

UI 参考物品信息卡：近黑色内容底、暗棕价格卡、棕金包边、少量内描边、温暖的金色标题与米白正文。整体像旅商的商品账册和展示柜，清晰分区，不使用都市警示图形、亮橙色操作块或暖白标题条。

场景、角色与道具继续复用现有日式动画资源；本次参考只改变 UI，不把所有物品改成像素图，不照搬参考图的名称、食物类型或“饱食度35”。信息必须来自游戏真实数据。场景仍通过现有独立分层接口更新，文字、数值、网格不得烘焙到图片。

## 5. 字体规范

正文与操作使用 PingFang SC / Noto Sans CJK SC / Microsoft YaHei。标题使用 Songti SC / Noto Serif CJK SC / SimSun，呼应参考图的古典气质；通过 `PopupSkin.font(bold)` 获取，不在页面单独创建字体。

| 层级 | 字号 | 使用场景 |

| 页面标题 | 24 | 行情、改装、管理确认 |
| 窗口标题 | 20 | 背包、设备、对白姓名 |
| 正文 / 操作 | 16 | 描述、按钮、属性行 |

## 6. 页面布局规范


- 固定场景、连续柜台与主库存作为经营页中心。顾客可见区优先于浮窗；普通背包和设备不添加全屏遮罩。
- 日期/城市/金币位于左上；行情与改装紧随其后，右上保留帮助与营业状态，不设置顾客背包按钮。
- 顾客背包默认 `(24,104)`，24×4 格；旅行背包默认 `(24,320)`，容量读取状态；交易账单默认右侧 `(1180,324)`，400×536 px，列表滚动，窗口限制在画面内。
- 仅售货顾客到场时自动显示顾客背包，仅收购物品的顾客不显示背包，不显示关闭按钮，Esc不关闭；仅顾客离开时自动关闭。标题栏仍可拖动，库存与投放规则保持不变。
- 对白默认 `(960,104,360,170)`；历史窗口默认 `(1180,292,320,540)`，可拖动。
- 工作台默认 `(280,492)`、炼药器 `(816,470)`、烹饪锅 `(24,600)`，尺寸由既有网格决定。并行打开互不关闭，窗口遮住底层交互时不允许穿透。
- 经营与战斗旅行背包仅显示中性网格和物品本体，不绘制腰包绿色区域、相邻加成连线、物品加成角标或组合效果面板。悬停或拖动加成道具时临时显示实际占格高亮与半透明黄色的加成格，黄色使用共享 `BONUS_AREA` / `BONUS_AREA_EDGE`，仅标记真实占格上下左右的相邻格，排除自身、斜角与背包边界外；拖动按预放位置与旋转更新。武器详情卡直接显示已计入背包相邻与品质词条加成的最终攻击和实际攻击间隔；扩容、长武器、多条属性和长交易单须检查溢出。
- 行情/改装/确认属于管理或决策模态层，使用统一深色遮罩；普通交易、背包、设备和配方册不使用遮罩。
- 探索旅行背包位于左上，右上按阶段切换事件选项与战利品；玩家生命卡位于左下，主要操作位于底部中央。胡闹森林保留左下前景商人与右侧纵深敌人，角色姿态独立，森林用单张静态背景，前进不换景或滚动。镜头轻震和视觉停顿仅作用于场景，UI保持稳定。
- 基础间距 4/8/12/16/24 px。窗口拖动在 1600×868 内限制边界，关闭按钮热区至少 32×32；普通按钮 32/40 px，探索既有 52 px 大按钮保留。

## 7. 组件规范

运行时唯一入口为 `scripts/popup_style.gd`；兼容历史调用名称，新增代码只使用语义 token。

- 窗口：4–5 px 暗棕包边、1 px 棕金内描边、4–6 px 小圆角和克制阴影；标题与内容同为深底，由细棕线分隔。`draw_window()`、`window()` 和 `panel()` 共用参数。
- 按钮：暗棕底、金色主文字、棕金边框、小圆角；次按钮更暗。复用 `button()` / `close_button()`，保留悬停、按下、禁用和聚焦反馈。
- 网格：24 px 逻辑格，暗色底与弱棕线，物品本体优先。占格和旋转保持状态规则。
- 武器实际占用格由 `TradeState.FOOTPRINTS` / `footprint()` 定义，外接尺寸与图像比例仍由目录size提供。镐为T型，斧为头部与柄；长剑一律正面竖直、剑尖向上、握柄向下，不使用倾斜或透视素材，当前两列格子精度下按2×6占格。空格允许嵌入其他物品。拖放填色和选中描边沿实际占格轮廓；点击、旋转、自动收纳、顾客批量接收及背包相邻效果共用实际占格，不改变攻击、价格和耐久。
- 列表与管理卡片：弱分隔、稳定金额列；标题、当前值、成本与安装状态具有一致层级。
- 对白 / 历史：暖棕边框深底，金色姓名、米白正文；保留逐字、翻页和拖动。
- 场景提示：只显示名称，使用同一小型深色包边框。
- 物品卡：共享 `InteractHoverTip.show_item()`；宽396 px，高度按描述与真实属性行计算。顶部356×148 px预览框，图像等比显示；右上角“数量：N”。下方金色名称、两栏价格、描述、类型标签、详细数值绿边行。当前位置显示当前市场价格，右栏显示购入价格；数量不再占价格栏。
- 价格数据：购入价格为成功买入时的实际成本。批量议价按当时各物品行情价值分摊，按最大余数法分配整数金币，合计严格等于实际支付。初始物品、加工产物与战利品没有购买记录时显示“—”；不能填成当前行情。每个实体物品通常数量1。类型仅显示有意义的物品类型；小背包显示“背包”，不显示“商品”“旅商用品”等泛化标签。加工原料首先显示“材料”，再显示用途类型：矿石为“材料、矿石”，燃料为“材料、燃料”，炼药原料为“材料、药材”，生肉为“材料、食物”。显示标签不改变交易分类和加工规则。
- 属性数据：显示实际攻击、耐久、攻击间隔、恢复、护盾、燃料和已生效的背包效果；不虚构饱食度、稀有度或未实现能力。矿石与力量药剂的相邻加成数值在所有存放区域均显示，不要求已放入背包或已连接武器；矿石仅显示相邻武器攻击+3，力量药剂显示相邻武器攻击+2，与其饮用效果分列。同一物品卡可随耐久与效果变化刷新。
- 帮助 / 确认：窗口高224–492 px，按正文计算；按钮位于底部。关闭热区至少32×32。
- 血条、冷却和状态：深底、平面填充；颜色与数值配合，不随画面更换材质。

## 8. 交互规范


保持拖放、R 旋转、右键/Esc 取消、双击快捷操作、混合买卖、还价、跨日加工、战利品快捷拾取。主按钮按下轻微缩放，120 ms 恢复；悬停 120–180 ms。现有角色到场、卷帘门与森林过渡按玩法节奏保留，不强行缩短。

窗口层级：经营画面 < 完整背包/设备窗口 < 对白 < 交易清单 < 历史 < 配方册 < 管理/确认 < 探索 < 当前页道具悬停。覆盖区的绘制与点击必须一致；不能出现关闭控件浮到覆盖窗口上方。未拾取物品离开、营业结束等既有确认保留。正常操作不增加成功 toast，错误与必要状态保留。

## 9. 图像生成规范

UI 底板和文字优先使用共享程序组件。本次不生成纹理覆盖现有窗口。新增美术使用清晰日式动画画法、稳定轮廓、成组阴影和少量高光；避免密集写实纹理、过量发光、模糊与字号不可读的伪像素化。不要从已归档的都市 UI 提示词重新引入亮橙操作块、斜线或切角。

普通材料保持自然材质与身份特征；设备继续正面正交视角与既有占格比例。透明图标输出 RGBA，96 px/格、主体最大填充94%，小于12的alpha清理。UI换风格不更改道具ID、占格、产物或数值。

补充细则见 [场景提示词](玩家主世界画风提示词.md)、[道具提示词](道具生成提示词.md)；运行资源见 [美术资源](美术资源.md)。实际基准见 [验收记录](../testing/统一UI改版验收.md)。

## 10. 后续维护

后续改动先读本规范并复用共享组件；新规则同步修改规范、运行实现、生成分支、Wiki和实际截图。历史都市风格归档，不用于当前生成。实际截图输出到 `docs/testing/previews/unified-ui/`，它始终对应本版本。

- 所有弹窗底板、内容和按钮归属同一窗口节点，按钮继承窗口层级，不单独提高 z_index。覆盖窗口时必须完整遮挡其内容与按钮。
- 玩家界面不显示格子尺寸、总格数或物品占格数；真实网格、容量和物品比例保持原规则。删除重复说明和无实际内容的提示，仅保留名称、有效属性、操作与错误反馈。

- 关闭按钮统一 32×32 px，标题栏高 48 px，垂直居中（y=8），右侧留白 16 px；使用共享 `close_button` 与 `place_close`，禁止页面单独偏移。关闭符号采用正文无衬线字体，按钮内部留白对称。


## 配方册组件

[配方册参考](references/配方册参考.png)用于图示和装订页结构。配方是可拖动的独立册子，520×620 px，默认位置 `(24,112)`，层级60；没有全屏遮罩，册外设备、背包和交易仍可操作。标题栏拖动限制在可见画布内，Esc仅关闭册子，关闭按钮仍复用统一定位与尺寸。

配方册作为实体书页采用共享 `BOOK_PAPER #D7CBB2`、`BOOK_INK #493C31`、`BOOK_WASH #C2A29C`；装订脊、少量金属环、淡色图示底由 `draw_notebook()` 绘制。商报复用同一纸底与印字颜色；其余窗口继续使用深色棕金体系。

图示只复用真实物品和设备图标：锻造材料图保留真实轮廓和矿石身份；炼药展示实际材料数量。箭头连接材料、可替代燃料、设备和产物；时钟标记次日完成。燃料区共用同一展示：不指定燃料的配方仅显示通用燃料图标与“任意燃料”，指定燃料的配方显示对应道具图标和名称；不展示纯度、耐久倍率、燃料对应瓶数或替代列表。不显示网格数和大段规则说明，不添加自动填充、即时加工或未实现的可选原料。

- 物品卡“详细数值”仅在真实属性行非空时显示，空物品卡隐藏标题、分隔线和整个数值区。回血属性以目录 `heal` 和共享背包效果计算，包含可直接食用的生肉；不按“食物”交易分类判断是否回血。

- 所有正式道具图标使用游戏风格的透明RGBA PNG，经 `scripts/item_art.gd:ITEM_TEXTURES` 统一加载；不得接入旧SVG或恢复程序绘制道具回退。UI边框、网格、箭头和模块图示可继续使用共享程序组件。

## 交易账单布局（2026-10-02）

[交易面板参考](references/trade-ledger-reference.png)用于账单分区和阅读顺序；颜色、字体、边框与按钮复用本规范和 `scripts/popup_style.gd`，实现为 `scripts/trade_panel.gd`。

- 400×536 px，默认位置(1180,324)。48px标题栏居中显示“交易账单”，右上角使用统一关闭按钮；标题栏可拖动，全部控件随窗口移动。
- 上方左侧为顾客意向，右侧为当前预算，全部金额为整数金币。
- 单向交易使用“购入/出售 N 件”清单标题，双向交易才显示两个切换页。连续底板配轻分隔，列表只保留图标、名称和右对齐行情价；可见高度192px，长清单内部滚动。
- 底部结算带大字显示支付/收取净额。单向附行情合计，混合附两方向实际报价，区分行情价与议价结果。净额展示不改变原有资金校验：玩家仍须满足买入报价的资金要求。
- 还价输入与提交共用一行，成交与撤回共用底部一行。无待交易物品时隐藏还价，并禁用成交/撤回。
- 窗口覆盖区及标题栏拖动期间屏蔽底层拾取、悬停和投放，保持视觉层级与点击层级一致。
- [两种尺寸实际基准](../testing/previews/unified-ui/README.md)。

## 行情商报组件（2026-10-02）

参考 [《深空当铺》事件与报纸](https://probablystolen.gamewikistation.com/zh-cn/systems/events/) 的新闻线索方式。商报1040×744 px，默认(280,78)，保留原行情面板的模态遮罩、Esc关闭、关闭按钮及商路入口。

- 使用共享 `NEWS_PAPER` / `NEWS_INK`（沿用配方纸色）、`NEWS_MUTED #796852`、`NEWS_RULE #9A8262` 和 `newspaper_panel()`。报头36px，新闻标题28/22px，正文18/16px，栏目14px；正文沿用全局无衬线字体，标题沿用全局宋体。
- 报头为当前城市商报名，署当日日期与市集。左栏592px展示本城新闻及近期街头消息，右栏328px展示城市见闻和日常新闻；分栏使用细印线，不使用逐条卡框。内容区高496px，两栏各自滚动。
- 新闻稿来自 `CityEconomy.news_articles()`，只报道当前事件和已经进入预告范围的传闻；不遍历整个周期生成日历，不显示事件起止日、倍率、价格列表、涨跌幅或压力层数。
- 通过采购、卸货、缺货、工班饭食等自然叙述暗示相关商品，不增加“受影响类型”标签或直接的买卖建议。背景新闻不改变价格。
- 顾客情报与兼容 `market_report()` 同样只输出叙事消息；熟客的提前消息范围保留，但不公开具体倒计时。内部价格、事件日程、关系与供给压力规则保持原实现。
- 底部仅保留商路通告与真实旅行按钮，票价35 G属于操作成本，不是行情预测。柜台与物品卡仍显示当前实际行情值。
