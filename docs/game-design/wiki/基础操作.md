# 基础操作

[返回 Wiki 首页](README.md)

## 商车内

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 移动物品，在库存、背包、柜台和设备区域之间放置 |
| 拖动时按 `R` | 旋转当前物品 |
| 双击普通物品 | 快速移入柜台；柜台上的物品会快速移回原归属区域 |
| 双击小背包 | 打开 6×6 旅行背包 |
| 双击加工设备 | 打开对应设备窗口 |
| 右键 | 取消当前拖动 |
| `Esc` | 取消拖动，或关闭当前模态窗口、背包和最上层设备窗口 |
| 拖动窗口标题栏 | 移动交易、背包、设备和历史记录窗口 |

柜台没有格子限制。物品放入柜台后会受到重力、碰撞和堆叠影响；橱柜、货架、背包和设备仍使用格子占位。

## 探索中

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 在旅行背包与战利品区域之间移动物品 |
| 拖动时按 `R` | 旋转当前物品 |
| 双击背包中的食物或药剂 | 在备战或战斗阶段使用该物品 |
| 双击战利品 | 自动寻找旅行背包中的可用位置 |
| `Ctrl` + 左键战利品 | 自动拾取，效果与双击相同 |
| 右键或 `Esc` | 取消当前拖动 |

战斗开始后不能重新拖动背包物品，但仍可双击使用允许的消耗品。胜利后可整理背包并拾取战利品。
