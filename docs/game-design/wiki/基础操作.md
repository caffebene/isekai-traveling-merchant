# 基础操作

[返回 Wiki 首页](README.md)

希尔薇入队后，车门出发窗口以人物卡片选择独自探索或希尔薇，点击前往野外确认；返回/Esc取消。探索救场与战后对白点击继续逐页阅读，期间战斗计时暂停，完成后恢复战斗或整理奖励。

## 商车内

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 移动物品，在库存、背包、柜台和设备区域之间放置 |
| 拖动时按 `R` | 旋转当前物品 |
| 双击普通物品 | 快速移入柜台；柜台上的物品会快速移回原归属区域 |
| 双击小背包 | 打开 6×6 旅行背包 |
| 双击加工设备 | 打开对应设备窗口 |
| 右键 | 取消当前拖动 |
| `Esc` | 取消拖动，或关闭当前模态窗口、旅行背包和最上层设备窗口；顾客背包保持显示 |
| 拖动窗口标题栏 | 移动交易、背包、设备和历史记录窗口 |

柜台没有格子限制。物品放入柜台后会受到重力、碰撞和堆叠影响；橱柜、货架、背包和设备仍使用格子占位。武器按轮廓占格：镐为T型，斧头与斧柄形成不规则形状，武器边侧的空格可放其他物品。按R会同时旋转图片和占格轮廓；相邻效果只在实际占用格的边缘接触时生效。

售货顾客的背包随到场自动显示，仅收购物品的顾客不显示背包，顾客离开后自动关闭；没有顶部入口或关闭按钮，仍可拖动标题栏移动位置。

## 探索中

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 在旅行背包与战利品区域之间移动物品 |
| 拖动时按 `R` | 旋转当前物品 |
| 双击背包中的食物或药剂 | 在备战或战斗阶段使用该物品 |
| 双击战利品 | 自动寻找旅行背包中的可用位置 |
| `Ctrl` + 左键战利品 | 自动拾取，效果与双击相同 |
| 右键或 `Esc` | 取消当前拖动 |

战斗开始后不能重新拖动背包物品，但仍可双击使用允许的消耗品。事件结算和战斗胜利后可整理背包并拾取战利品。事件献祭有多件候选时，点击选项后点选具体背包物品；右键或Esc取消点选。

## 统一界面（2026-10-02）

经营、探索、改装、加工、历史与悬停共用深色面板、米白无衬线文字和棕金主操作。行情以纸色商报展示新闻与传闻，配方采用纸色册子，两者沿用共享字体和操作组件。交易清单默认位于右侧；顾客背包和旅行背包默认位于左侧，窗口标题栏仍可拖动。设备窗口可独立并行打开；覆盖区域阻止点到底层场景。

手机仍打开历史对话，历史窗口改为与其他窗口相同的外壳。对白保留逐字与前后翻页。移除常驻底部操作提示，原拖放、旋转、双击与右键/Esc操作保持；场景物悬停显示名称，道具悬停显示完整属性。

浮窗使用深色棕金标题栏、深色内容区与棕金主操作；标题条继续支持原有拖动。

帮助菜单已同步交易、设备、探索与旅行入口；短确认窗口按内容收紧高度。

弹窗的底板、内容和按钮整体显示与遮挡；背包、设备和物品信息不再显示格子尺寸或总格数，实际空间和放置规则保持不变。
关闭按钮统一放在标题栏右侧，使用相同尺寸、居中位置和留白。

森林遭遇逐页点击“继续”阅读，最后一页选择动作；结果读完进入战利品整理。没有固定路程或通关终点，首领后也能继续。备战和战斗都可逃跑，事件与结算阶段可返回商车。

砍伐/采矿选项有多把可用工具时，先点选项再点具体斧头/镐子，右键或Esc取消。工具只扣耐久、不作为献祭删除。

## 顾客对白与供货故事

开门和呼叫铃迎来随机顾客，姓名行显示所属阵营。货品、预算和开场白每次到访可能不同；同次在场不刷新货物。按原交易操作供矿、熟食、武器或药剂可推进人物故事，成交后播放回应；不另设任务清点窗口。希尔薇首次成功交易后才提出树心需求，翻到该页即可记录委托。详见[经营与交易](经营与交易.md)。
