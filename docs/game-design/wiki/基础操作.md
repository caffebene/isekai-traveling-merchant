# 基础操作

[返回 Wiki 首页](README.md)

## 商车内

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 移动物品，在库存、背包、柜台和设备区域之间放置 |
| 拖动时按 `R` | 旋转当前物品 |
| 双击普通物品 | 快速移入柜台；柜台上的物品会快速移回原归属区域 |
| 双击小背包 | 打开 6×6 旅行背包 |
| 双击加工设备 | 打开对应设备窗口 |
| 右键 | 取消当前拖动 |
| `Esc` | 取消拖动，或关闭当前模态窗口、背包和最上层设备窗口 |
| 拖动窗口标题栏 | 移动交易、背包、设备和历史记录窗口 |

柜台没有格子限制。物品放入柜台后会受到重力、碰撞和堆叠影响；橱柜、货架、背包和设备仍使用格子占位。

## 探索中

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 在旅行背包与战利品区域之间移动物品 |
| 拖动时按 `R` | 旋转当前物品 |
| 双击背包中的食物或药剂 | 在备战或战斗阶段使用该物品 |
| 双击战利品 | 自动寻找旅行背包中的可用位置 |
| `Ctrl` + 左键战利品 | 自动拾取，效果与双击相同 |
| 右键或 `Esc` | 取消当前拖动 |

战斗开始后不能重新拖动背包物品，但仍可双击使用允许的消耗品。胜利后可整理背包并拾取战利品。

## 统一界面（2026-10-02）

经营、探索、行情、改装、加工、历史与悬停共用深色面板、米白无衬线文字和橙色主操作。交易清单默认位于右侧；顾客背包和旅行背包默认位于左侧，窗口标题栏仍可拖动。设备窗口可独立并行打开；覆盖区域阻止点到底层场景。

手机仍打开历史对话，历史窗口改为与其他窗口相同的外壳。对白保留逐字与前后翻页。移除常驻底部操作提示，原拖放、旋转、双击与右键/Esc操作保持；场景物悬停显示名称，道具悬停显示完整属性。

浮窗使用暖白标题条、深色内容区与橙色主操作；标题条继续支持原有拖动。

帮助菜单已同步交易、设备、探索与旅行入口；短确认窗口按内容收紧高度。
