## 商车设施

| 设施 | 功能 |
| --- | --- |
| 柜台 | 放置顾客与玩家的待交易物品；支持自由落体和物品堆叠 |
| 一体机 | 打开或关闭交易清单 |
| 行情板 | 阅读本城商报与近期传闻；周期第 7 天可由此启程 |
| 改装 | 购买并安装商车模块，最多同时拥有两个 |
| 手机 | 打开或关闭已经播放过的历史对话 |
| 呼叫铃 | 无顾客时点击呼叫；有顾客时长按更换下一位顾客 |
| 关门器 | 结束营业并关闭橱窗卷帘门；次日再次点击可开门营业 |
| 卧铺 | 卷帘门关闭后推进到下一天 |
| 左侧车门 | 卷帘门关闭后进入野外探索 |

柜台上还有未处理物品时，不能直接更换顾客。卷帘门打开时不能使用卧铺或出门探索。

## 库存区域

| 区域 | 容量 | 说明 |
| --- | --- | --- |
| 商车橱柜 | 30×12 | 主要库存区 |
| 顾客背包 | 24×4 | 顾客带来的商品与结算后接收的物品 |
| 旅行背包 | 6×6 | 外出探索时唯一随身携带的库存 |
| 柜台 | 无格线 | 交易暂存区，使用物理摆放 |

物品必须完整放入格子区域，不能重叠或越界。长形物品可以旋转；部分自动收纳流程也会尝试旋转后再判断空间。

仅售货顾客在场时自动显示背包；仅收购物品的顾客不显示背包。没有顾客背包按钮或关闭按钮，Esc不关闭该窗口；顾客离开（更换顾客或结束营业）后自动关闭，新顾客有售卖物品时重新显示。

## 交易流程

1. 把顾客物品拖到柜台，表示向顾客买入。
2. 把自己的物品拖到柜台，表示向顾客出售。
3. 使用一体机查看交易账单；柜台同时存在双向货物时，可切换“购入”和“出售”页。
4. 点击底部“购入/出售 N 件”（双向货物时为“完成混合交易”）成交，或修改“还价”金额并点击“提出还价”。
5. 结算后，卖给顾客的物品进入顾客背包；从顾客处买入的物品仍留在柜台，需要手动收回库存。

顾客只收购自己感兴趣的类别。无意愿物品可以暂放柜台，但不会进入交易清单。顾客也只出售其资料中指定的商品。交易估值使用当前城市行情，而不是物品图鉴中的固定基础价。

## 报价与议价

- 顾客出售商品时，初始要价为本地行情价合计的 112%。玩家报价达到行情价合计的 94% 时可被接受。
- 玩家出售商品时，顾客初始报价为本地行情价合计的 86%。玩家要价不高于行情价合计的 110%，且不超过顾客可用资金时可被接受。
- 每位顾客初始有 3 点耐心。未被接受的还价消耗 1 点耐心；耐心耗尽后不能继续还价，成功结算后耐心恢复为 3。
- 混合交易中，玩家买入支付的金额会计入顾客可用于收购的资金。
- 金币、顾客资金或顾客背包空间不足时，交易不会扣款，也不会转移任何物品。
- 撤回交易时，物品优先回到进入柜台前的位置；原位置被占用时会尝试寻找其他空位。

## 顾客与阵营

来客属于森林守望、炉桥工班、南门街坊、巡夜队或夜路行会。对白姓名带阵营，手机记录保留身份。每次来访成功交易可使所属阵营交情+1，最高10；同次来访分批交易不重复加阵营交情。每次成功结算仍使个人关系+1，最多5，达到2后可能谈起本城近期消息。

首次运行、换客和次日开门均随机抽取已开放人物，避免与上一位相同。本城人物、已建立交情的阵营更常来；树心主线进行时希尔薇概率提高。久未出现者会被优先安排，十人池按最多30次换客验收，不再按四人顺序循环。售卖种类和数量从本人货品池抽取，预算也在各自范围内变化；同一位顾客在场时不刷新货品和预算。

给诺拉累计卖2件武器，后续货品池加入辉铁剑。给阿雀卖2瓶力量药剂，后续古藤木更常见。给赫伯特卖3份古藤木/粘液，修井故事完成，货品池加入辉铁剑。给伊芙卖3份面包/烤肉，晚饭故事完成，货品池加入防护药剂。结果对白只播一次，后续货物仍须正常付费，没有重复免费奖励。

希尔薇到场先正常做材料生意。**首次成功与她交易后**才播放树心需求；读到委托页后，古树Boss胜利保证掉月蚀树心。中途未听完可在下次补说，交易失败不能触发。必须把真实树心卖给当前顾客希尔薇并成功结算，才开启空心鹿王主线；持有、放柜台、撤回或卖给别人不算交付。入队后她仍正常做材料生意。进度跨返回、休息与旅行保留在当前会话，无磁盘存档。

详细人物性格、随机规则和故事见[顾客阵营与故事](../顾客阵营与故事.md)。连续向同一城市出售同类商品仍会压低本地需求，每日逐步恢复。

成交回应按本次买入、出售或混合交易选择；日常成交只保留一页，人物委托和故事进展仍使用多页。对白中收款和接收物品的方向与真实交易一致。

## 结束一天

点击关门器并确认后，卷帘门关闭、顾客离开，当天营业结束。此时可使用卧铺推进日期；所有满足条件的加工设备会统一结算。进入下一天后，当日成交次数与收支统计清零，点击关门器重新开门即可继续营业。

## 窗口布局（2026-10-02）

交易账单默认靠右，可拖动标题栏。顶部显示顾客意向和预算，中部显示物品图标、名称与行情价，底部显示支付或收取金额与成交操作。单向直接显示清单，混合买卖才出现切换页；长清单可以滚动。底部金额为双方报价的差额，混合交易仍须满足买入报价的资金要求。顾客和旅行背包靠左。对白与历史由统一程序面板显示，手机与交易终端仍可再次点击关闭各自窗口。

## 品质武器价格

顾客售卖武器生成时随机获得品质，具体概率为隐藏数值。武器实例价格＝目录基础价格×品质倍率×当前城市行情倍率，四舍五入为整数金币。品质倍率依次为1、1.5、2.2、3.2、5；词条不额外加价，耐久损耗不额外折价。

交易清单、议价基准、合计和信息卡使用同一实例价格；混合买卖保留原资金校验。批量议价的购入成本按实例行情价格分摊，整数成本之和严格等于实际支付，后续行情变化不修改历史购入价格。
