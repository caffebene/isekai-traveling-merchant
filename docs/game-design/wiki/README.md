# 《异世界旅商》游戏 Wiki

《异世界旅商》是一款以空间库存、面对面交易、跨日加工和野外探索为核心的旅商经营游戏。玩家在商车中接待不同需求的顾客，通过买卖和议价积累金币，再把探索获得的材料加工成食物、药剂与装备。

本 Wiki 记录当前项目中已经实现的玩法，规则与数值以游戏代码为准。最后同步日期：2026-10-02。

## 核心循环

1. 阅读本城商报，从新闻和近期传闻推测供需，决定囤货和加工方向。
2. 整理商车库存，把武器、食物和药剂装入旅行背包并组成位置联动。
3. 开门营业，接待顾客并在柜台上完成买入、出售和议价。
4. 将原料放入烹饪锅、炼药器或工作台，利用跨城价差安排产出。
5. 关闭卷帘门后探索，权衡继续深入或带着战利品撤退。
6. 休息推进日期；周期第 7 天可支付路费前往另一座城市。

## 当前版本范围

- 经营地点：风栖镇与铁砧城，两城拥有不同基础供需和周期事件。
- 顾客：五个阵营、十位随机来客，初始七位；救助猎人及完成供货故事可解锁其余三位，货品与预算随机。
- 探索样板：无限探索、10类事件、5种普通敌人和2个首领；已实现希尔薇委托与同行。
- 已实现系统：空间库存、自由物理柜台、双向交易、动态行情、城市事件、顾客阵营、随机来客与供货故事、关系情报、议价、顾客预算、跨日加工、跨城旅行、背包战斗联动、无限森林探索、随机事件与首领、战利品拾取、商车模块。
- 探索可解锁营业顾客；希尔薇成功交易后才提出需求，主线靠真实掉落、成交、救场与战后对白推进，后续以角色卡片选择同行。
- 当前没有持久化存档；关闭游戏后原型状态会重置。
