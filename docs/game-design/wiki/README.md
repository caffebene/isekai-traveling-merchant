# 《异世界旅商》游戏 Wiki

《异世界旅商》是一款以空间库存、面对面交易、跨日加工和野外探索为核心的旅商经营游戏。玩家在商车中接待不同需求的顾客，通过买卖和议价积累金币，再把探索获得的材料加工成食物、药剂与装备。

本 Wiki 记录当前项目中已经实现的玩法，规则与数值以游戏代码为准。最后同步日期：2026-09-23。

## 核心循环

1. 整理商车库存，把武器、食物和药剂装入旅行背包。
2. 开门营业，接待顾客并在柜台上完成买入、出售和议价。
3. 将原料放入烹饪锅、炼药器或工作台。
4. 关闭卷帘门并在卧铺休息，推进到下一天并结算加工。
5. 从车门进入野外，战斗、拾取材料，再返回商车继续经营。

## 当前版本范围

- 经营地点：风栖镇商车。
- 顾客：4 位，按固定顺序循环出现。
- 探索敌人：5 种，随遭遇次数循环出现。
- 已实现系统：空间库存、自由物理柜台、双向交易、议价、顾客预算、跨日加工、旅行背包、探索、自动战斗、战利品拾取。
- 当前没有持久化存档；关闭游戏后原型状态会重置。
