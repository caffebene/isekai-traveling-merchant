# 探索与战斗

[返回 Wiki 首页](README.md)

背包与战利品中的武器按实际轮廓占格，镐柄两侧可嵌入小物品。旋转、自动拾取和相邻加成均依据实际占用格；空外框的边缘接触不会触发武器加成。

## 出发准备

希尔薇同行解锁后，从关门后的车门出发会显示角色卡片。点击独自探索或希尔薇后点击前往野外；返回/Esc取消出发，不改变已选同行。同次外出不能中途切换。

先把武器、食物和药剂放入 6×6 旅行背包，再关闭卷帘门并从左侧车门进入野外。商车橱柜中的物品不会自动带入探索。

每次新外出会恢复至 60 点生命。生命会在同一次连续探索中保留；护盾与力量效果会在每次新战斗时重置。

## 无限森林探索

受伤猎人奥林可能被自己的套索困住，或追鹿摔伤。指定旅行背包中的1瓶防护药剂救助，解锁之后营业回访；只消耗一次，他不再作为受伤事件出现。缺药禁用救助，临时包扎或绕开不解锁回访。

首次与希尔薇成功交易，再读到月蚀树心委托后，普通古树Boss胜利保证先生成1颗树心。按原战利品操作带回，并实际卖给希尔薇，下一次探索战斗会遭遇210生命、18攻击的空心鹿王。未拾取、丢失或卖给别人后，后续古树仍可再次掉落。

鹿王首次出手前有保留最后1生命的月封；首次出手将玩家打至1生命并清除护盾，进入暂停战斗的救场对白。推进到希尔薇出现页才回满60生命并加入本次战斗；读完恢复计时。救场只在该次战斗触发一次，井欠账在首击消耗；后续攻击沿用普通护盾规则。逃跑或战败可重试，不会提前解锁同行。

实际击败鹿王后，读完三页战后对白才解锁之后的同行卡片。希尔薇每4秒独立射击造成6伤害，不消耗玩家耐久/行动力，不触发武器效果，不占背包。她没有独立生命条，败退仍依据旅商生命；选择跨外出保留，普通无限探索继续。对白期间攻击计时暂停，奖励在战后对白完成后可整理。

没有路程上限。战斗、随机故事和之前选择留下的后续交错出现；古树首领胜利后仍可继续，直到死亡、主动返回或逃跑。事件不增加战斗深度；最多连续两个事件，再安排战斗。

点击探索或继续探索前进；背景是单张静态森林，前进时商人行走、背景轻度虚化，抵达恢复清晰；前进与入场共0.65秒。事件逐页阅读对白，最后出现选择；选择按钮只表达动作和可能影响，没有下方提示或精确概率。结果演出后保留一页剧情结果，点击继续就能整理奖励，不再出现行李清点页。备战与战斗中都可逃跑，随机遗失背包1件并返回；事件与结算阶段可主动返回。

## 工具采集与新居民

携带可用斧头时可能遇到枯树，携带可用镐子时可能遇到矿脉。必须在玩家旅行背包中、当前耐久至少1；橱柜与顾客物品不算。斧包括赤铜斧、辉铁斧、淬火斧，镐包括赤铜镐、辉铁镐。

| 遭遇 | 动作与真实结果 |
| --- | --- |
| 摇晃的枯树 | 粗枝采集扣所选斧3耐久，小枝扣1耐久，绕开不扣。随机得木×2或木＋果；打鼾剧情重砍可能挨枝条，损失6生命 |
| 路边矿脉 | 深挖扣所选镐3耐久，小采集扣1耐久，绕开不扣。深挖可能得辉铁矿×2或混合矿，裂壁可能落石伤害5；小采集稳定赤铜矿×1 |
| 倒班篝火 | 普通休息有瞌睡/值班剧情，分别为12恢复或4伤害随机 / 稳定恢复10。添古藤木恢复24，留下下一次可恢复16的余火；用后清除，不叠加 |
| 蜗牛收费站 | 付10G或献绯红果换放行与材料；强行跨过可能被绊伤4。真实付费两次或喂过果子，后续才免费放行并赠草 |

有多把符合本次耐久条件的工具时，可点选具体工具；只有这一把损耗。剩余耐久不足时对应选项禁用，1耐久仍可小采集。耗尽后保留损坏工具，战斗跳过它；满包奖励留在战利品区整理。采集不触发武器暴击/吸血，不扣行动力，不推进战斗时间，也不增加战斗深度。

献祭消耗指定真实实体，有多件同类时点选目标；右键或Esc取消。缺少资金或物品时禁用。随机失物可命中武器和贵重物品，隐藏夹层不保护事件失物或献祭；空包跳过失物。事件致死按战败规则处理，不发本次奖励。

判决跨事件保留，下一场生效一次，战斗结束或逃跑清除。井债在首领首次攻击先翻倍再抵扣护盾，出手即结清；还款也可清债。角色关系、未结官司与欠款跨外出保留在当前游戏会话；回商车清除本次战斗判决，重新出发恢复生命和战斗深度。退出程序后不保存。

详尽剧情与对白见[胡闹森林设计](../胡闹森林.md)。

## 战斗规则

- 开始战斗时立即自动攻击一次，之后按冷却持续攻击；可用武器基础间隔2秒，每次攻击消耗1点耐久。
- 多把武器同时携带时会轮流攻击，而非只使用第一把。
- 与武器正交相邻的矿石使该武器伤害 +3，不改变攻击间隔；相邻力量药剂使武器伤害 +2。
- 位于旅行背包最左侧两列的消耗品属于腰包区，战斗中使用不消耗行动力。

经营与战斗旅行背包不显示绿色腰包区域、相邻加成连线、物品加成角标或“当前组合效果”。悬停武器直接查看加成后的最终攻击和实际攻击间隔；腰包与相邻加成仍按原规则生效。悬停或拖动矿石、力量药剂、燃料时，物品自身占格高亮，上下左右的相邻格以半透明黄色显示加成范围；拖动时范围跟随预放位置，裁切在背包边界内，不包含自身或斜角。离开悬停或结束拖动后恢复中性格线。
- 没有可用武器时，开战立即进行5点徒手攻击，后续基础间隔2秒。
- 敌人每 3 秒攻击一次；护盾优先抵消伤害。
- 力量药剂使本场战斗伤害提高 20%，同一场战斗不能重复叠加。
- 食物在满血时不会被消耗。
- 战败会清空旅行背包内的全部物品并返回商车。

## 战利品

事件结算和战斗胜利后都可以手动拖动战利品，也可以双击或按住 `Ctrl` 点击自动收纳。自动收纳会依次尝试物品当前方向和旋转方向，从背包左上角寻找首个可用位置。

选择继续探索或返回商车时，尚未拾取的地面物品会被丢弃；存在未拾取物品时会先要求确认。

## 风险与商车模块

探索界面显示遭遇次数、事件/普通/精英/首领类型、临时后果与当前武器组合。生命、武器耐久和已占用背包空间都会跨遭遇保留，使继续深入成为收益与损失风险之间的选择。

- 车顶货架：把旅行背包由 6×6 扩展为 8×6。
- 隐藏夹层：战败时保留旅行背包中本地行情价值最高的 2 件物品。
- 行军灶：生肉、面包和烤肉额外恢复 8 点生命。

商车最多安装两个模块。改装台用三张模块卡显示改装前、改装后、价格和安装后的验证方式；安装后卡片立即切换为“已启用”。车顶货架会扩大背包可用空间，隐藏夹层的保护状态与行军灶带来的最终恢复量在物品详情中展示，不添加物品角标或组合面板。

## 界面外观（胡闹森林）

森林采用单张静态背景，不滚动、不换层、不前进缩放。商人位于左下前景，提供待机、行走、攻击、受击、用物、惊讶六姿态；敌人与事件角色位于右侧中景。旅行背包在左上，右上在事件选择和战利品之间切换；生命卡在左下，操作在下方。

UI沿用棕金账册样式。自动攻击会标示真实出手武器、攻击轨迹及实际伤害，敌人出手前有姿态预兆。视觉停顿和镜头轻震不暂停战斗计时，也不移动UI。战斗开始后不能重排背包，仍可主动双击用物。

## 品质武器的战斗效果

战利品与事件奖励中的武器随机生成品质，具体概率为隐藏数值；现有掉落表保持原状，只在奖励本身为武器时应用品质。

锋利攻击百分比先作用于武器基础攻击，再叠加相邻矿石和力量药剂的固定攻击加成。迅捷作用于已乘相邻燃料倍率的实际间隔。暴击×1.5与力量药剂×1.2一起计算，最终向上取整；吸血按实际造成伤害向下取整，包含击杀攻击，过量伤害不计入。徒手不触发武器词条。每次武器攻击仍消耗1点耐久，耐久为0不攻击。夹层保护按含品质的当前实例价格选取。


相邻燃料降低武器攻击间隔：史莱姆粘液每份降低10%，古藤木每份降低20%。多份相邻燃料倍率相乘，实际间隔为基础2秒 × 0.9^粘液数量 × 0.8^古藤木数量 ÷（1＋迅捷攻速加成）。燃料详情在任意存放区域显示百分比，背包悬停与拖动显示黄色相邻范围；武器详情显示计算后的实际秒数。矿石不影响间隔。
