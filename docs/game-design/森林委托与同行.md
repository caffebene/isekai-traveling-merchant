# 森林委托与同行

2026-10-02。延续无限探索、单张背景、背包自动战斗与实体柜台。探索选择留下的人际事实回到营业；主线靠真实掉落和成交推进，不靠拥有物品或关闭窗口完成。当前进度保存在游戏会话，沿用无磁盘存档范围。

## 受伤猎人奥林

奥林尚未被救助时，受伤猎人加入基础随机池，权重1，仍遵循同事件间隔至少3次、连续事件最多2次。套索剧情中，他踩进自己的陷阱；摔伤剧情中，他追鹿时被树根绊下坡。开场先看见伤口，再听他说明经过，不假装初遇认识玩家。

| 动作 | 实际效果 |
| --- | --- |
| 递瓶防护药剂，替他稳住伤势 | 指定玩家旅行背包中1瓶真实防护药剂，消耗一次；药剂护住伤口，解锁营业顾客奥林 |
| 用干叶替他压住伤口，先缓一缓 | 临时照顾，不解锁康复回访 |
| 把水放在他身边，继续赶路 | 不消耗物品、不解锁顾客 |

救助后不再随机出现受伤版本。奥林加入统一随机顾客池，受本城与交情权重影响，不连续到访；首次开门也随机。预算120–160G、收购药剂，鲜兽肉/绯红果随机1–3件。康复立绘与受伤事件立绘独立。随机来客与新增阵营故事见[顾客阵营与故事](顾客阵营与故事.md)。

## 希尔薇主线：林心之路

| 阶段 | 真实触发 | 下一步 |
| --- | --- | --- |
| 未委托 | 先与希尔薇成功交易，再阅读树心委托页；逐字完成、点击揭示或浏览到该页均记录 | 寻找月蚀树心 |
| 已委托 | 普通月蚀古树王胜利 | 保证在战利品中先放1颗树心，再生成普通掉落 |
| 已交付 | 希尔薇作为当前顾客，真实成交批次包含树心，所有交易校验通过 | 下一次探索战斗进入空心鹿王领地 |
| 已救场 | 鹿王首次出手；玩家读到希尔薇救助页 | 从1生命回满60，希尔薇加入本次战斗 |
| 胜利待对话 | 实际击败鹿王 | 三页战后对白，奖励暂不可拾取 |
| 同行解锁 | 阅读完战后对白 | 后续出发显示独自探索/希尔薇角色卡片 |

月蚀树心为材料、基础估值80G、2×2，无新增加工配方或战斗消耗效果。库存持有、卖给别的顾客、放柜台、撤回或成交失败都不交付；仍处于已委托时，每次普通古树Boss胜利都可以再次掉落，丢失和未拾取不会卡死主线。满背包时仍先在战利品生成，由玩家自行收纳。

交付后，空心鹿王优先于随机故事成为下场战斗，既有故事后续票据保留。它210生命、18攻击、3秒周期；不套用深度倍率和每三层精英调度。开场有空壳封月的叙述。首次出手前最后1点生命由月封保留，实际伤害按剩余生命结算，生命条始终真实。首次攻击直接令玩家生命为1并清除护盾，随后进入故事阶段。井欠账若仍存在，在该次首击消耗，不与剧情定值叠乘。

救场先展示跌倒与1生命；推进到希尔薇出现页才回满血并加入队伍。故事期间实际战斗时间与双方攻击计时暂停；读完继续真实战斗，后续鹿王攻击按18伤害和护盾正常结算，不能反复触发救场。救场后逃跑或战败不会解锁队友，后续可重战；重试再次保留救场段落，必须真正胜利并读完战后对白。若通过状态接口中断胜利对白，下次探索会补完，不直接解锁。

## 同行交互与战斗

出发入口仍为关门后的车门。未解锁时沿用原森林确认；解锁后显示两张可选角色卡：独自探索、希尔薇·弓援护。选择后点击前往野外，返回/Esc不出发、不改变已选同行。选择记住在当前会话；同次外出不能中途切换。

希尔薇每4秒射击造成6实际伤害，不消耗玩家武器耐久、行动力或背包空间，不触发玩家武器暴击/吸血/力量倍率。她没有单独生命池；胜败和撤退仍由旅商生命决定。命中通过独立攻击来源信号反馈，独立角色、箭轨迹与伤害数字；暂停和慢帧使用同一按时间顺序调度。单人卡取消跟随但不取消角色解锁。普通无限探索与旧事件继续存在。

## UI与实现接口

- 经营对白、成交回应、手机记录复用原组件；不增加任务清点窗口。
- 受伤猎人复用右上事件窗口，多页对白后出现三个动作；没有选项下提示。
- 救场与战后对白复用探索深底故事窗口和继续按钮。故事期间不显示继续探索、逃跑或收纳入口。
- 同行选择采用棕金外壳与共享按钮，两张人物卡及前往野外/返回；角色画面不烘焙文字。
- `TradeState.story_progress`保存主线阶段与猎人事实，`selected_companion`保存选择；`forest_story.gd`统一顾客对白、听到委托、真实售出与队友校验。
- `ExplorationState`增加故事阶段、首击开场标记、独立同行时钟；原事件选择、战利品与消耗品接口保持复用。

对应玩家规则见[探索与战斗](wiki/探索与战斗.md)、[经营与交易](wiki/经营与交易.md)。验证见[委托与同行验收](../testing/森林委托与同行验收.md)，两尺寸实际基准见[预览目录](../testing/previews/unified-ui/README.md)。
