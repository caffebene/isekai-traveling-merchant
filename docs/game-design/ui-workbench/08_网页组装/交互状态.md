# 运行时组装说明

本项目不把 HTML 当作最终运行层，Godot `Control` 与 `_draw()` 负责组装。这里保留换皮 Harness 的层级约束：

1. 背景纹理在最底层，城市和顾客通过 `scene_layers.gd` 独立替换。
2. 窗口外框、标题栏、网格、文字、价格和按钮全部运行时生成。
3. 交易清单、背包和设备窗口使用小尺寸独立窗口，窗口位置不是场景贴图的一部分；设备实例之间不互斥，关闭按钮挂在对应窗口宿主内。
4. 物品图标根据目标网格尺寸绘制，拖动幽灵不拉伸整张素材。
5. 每次 UI 修改都通过 Godot smoke 渲染输出截图，再检查窗口是否越界、列表是否溢出、格子是否错位。

## 金属场景覆盖层

交易场景的门、卧铺与工作台使用独立 RGBA 素材。门与卧铺按现有金属背景的透视与可用宽度做非等比形变，并通过透明像素蒙版保留真实可点击轮廓；悬停时复用 `hover_outline.gdshader` 显示白色边缘，并由 `scripts/interact_hover_tip.gd` 从物体右上方快速弹出只含名称的黑底白框提示。工作台在三张场景素材中位于最高层，同时保持 `mouse_filter = IGNORE`，运行时商品与交易窗口仍可绘制在其上方。
