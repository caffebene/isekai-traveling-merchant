# 运行时组装说明

Godot Control 与运行时绘制负责组装，HTML 不作为最终运行层。全局约束见 [整体视觉与UI规范](../../整体视觉与UI规范.md)。

- 背景、城市、顾客与交互素材独立分层，复用原有点击蒙版和场景接口。
- 窗口、网格、对白、标题、价格和状态由程序绘制，样式复用 popup_style.gd。
- 背包与设备可并行打开，关闭控件挂在各自宿主；交易/历史/管理面板按统一层级覆盖，关闭控件不能越过覆盖面板。
- 道具按原占格绘制；有效/无效投放与悬停使用统一状态反馈。
- 视觉变化保存实际游戏截图；点击、拖放和层级变化使用对应现有交互测试。验收与预览归 docs/testing/。
