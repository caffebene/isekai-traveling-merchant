# 经营页参考说明

本轮参考来源是用户提供的深空店铺截图与当前项目经营页。截图只作为结构和视觉语言参考，不把其中的角色、商标或完整界面直接复制进项目。

需要保留的结构语言：

- 店铺场景是固定底层，交易、背包和设备是叠在场景上的小型独立窗口。
- 交易窗口、背包窗口和设备窗口都有窄标题栏，可拖动，关闭按钮固定在右上角。
- 网格密度高，物品图标占格子，动态文字和价格由运行时绘制。
- 顾客货物在窗台外侧的桌板上，柜台在桌面上，底部主库存保持完整可见。
- 色彩以炭黑、米白和高饱和橙为主，青色只用于状态提示与次级高亮；使用硬边、斜切角、偏移阴影和不对称标签，避免木纹、黄铜圆角和羊皮纸面板。

当前项目的二次元顾客立绘、风栖镇背景和道具图标保留，只调整 UI chrome、密度、状态和窗口行为。
