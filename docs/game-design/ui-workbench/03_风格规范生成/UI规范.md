# 异世界旅商经营页 UI 规范

## 1. 项目定位

- 游戏类型：二次元奇幻旅商经营 / 网格交易模拟
- 目标平台：桌面 1600×900
- 核心体验：整理货物、接待顾客、在柜台完成交易、使用设备隔天加工、结束一天继续经营
- 参考语言：深空店铺的高密度库存、暗色工业窗口和紧凑交易信息；本项目保留二次元顾客与风栖镇美术

## 2. 视觉 token

本轮窗口换皮对齐《绝区零》的都市街头 / 模拟印刷 UI 语言，不把“暗色工业”误认为圆角绿色面板：使用黑炭底、米白文字、橙色主操作、青色状态点，配合硬边、斜切角、偏移阴影和不对称强调线。UI 文本使用无衬线字体，窗口标题不使用宋体或羊皮纸质感。

| Token | 色值 | 用途 |
|---|---|---|
| `ui.panel` | `#11181DF5` | 交易、背包、设备窗口底色 |
| `ui.panel_alt` | `#202A30` | 标题栏、按钮、选中态 |
| `ui.frame` | `#E7E4DC` | 硬边外框、关闭按钮、分隔线 |
| `ui.text` | `#F1F0EB` | 标题、主要信息、按钮文字 |
| `ui.muted` | `#A7AFB3` | 表头、辅助说明、快捷提示 |
| `ui.orange` | `#FF5A2F` | 主按钮、左侧强调条、选中态 |
| `ui.cyan` | `#32C5D1` | 状态线、次级高亮、可交互反馈 |
| `ui.warning` | `#D98683` | 错误、空间不足、拒绝交易 |
| `ui.item_accent` | 物品自身颜色 | 物品边框和稀有度识别 |

窗口采用 1px 米白硬边、左上/右下斜切角、偏移黑色投影和窄标题栏；标题栏带橙色竖条与青色状态短线。按钮采用直角平面状态，主按钮橙色、悬停切换青色，次按钮炭黑底配米白描边；不使用木纹、羊皮纸、黄铜圆角或全屏模态遮罩。

## 3. 布局与密度

- 主场景固定，不为打开背包、交易单或设备弹出全屏遮罩。
- 顾客区保持窗台外侧 24×4；柜台保持桌面 43×4；主库存保持下方 30×12，底边固定并向上增加两行。
- 通用场景和小背包格子统一为 24px，窗口内容区刚好容纳 6×6 格，以容纳 2×6 长剑。
- 交易清单宽 300px、高 330px，列表区域固定高度并滚动；按钮并排、短文案、小字号。
- 物品名称、类别、估值保持三列，不使用分类、整理等额外工具栏。

## 4. 交互状态

- 标题栏：默认可拖动，拖动时窗口随指针移动并限制在经营区域内。
- 物品：常态只绘制物品本体，不显示背景色和外轮廓；悬停复用黑底白框红色衬层但保持水平，完整显示名称、归属/类别、估值、占格、描述和操作信息；仅拖动时显示物品外轮廓及目标格子有效/无效颜色；按 `R` 旋转。非道具交互物则使用轻微左倾的名称专用提示。
- 交易：柜台允许买入与出售物品共存，清单可滚动，接受/撤回始终保持在窗口底部。
- 按铃：只负责呼叫下一位顾客，不显示“下一组货物”等系统化按钮文案。
- 顾客意愿：交易清单显示顾客购买的单一类别标签；非意愿物品可以暂放柜台但不进入交易清单，并通过角色对话框反馈“我没有意愿买这个”。顾客喜欢程度句也只进入角色对话框，不使用左下角 toast。
- 顾客资金：每位顾客进入时获得 100–200 G 预算，交易面板显示当前余额，顾客付款受余额限制。
- 混合交易：柜台同时存在顾客物品和玩家物品时，清单显示“购买 / 出售”两个标签页；买入物品结算后保留在柜台，等待玩家手动收纳。
- 对话框：直接复用 `assets/ui/dialogue-frame.png` 的白色几何边框与黑色内容区，放置在橱窗右上方标注区域；角色名放在顶部白色标题片，正文限制在黑色内容区并按字符换行，右下角保留前后翻页按钮，每句完成后短暂停顿并清空，再输出下一句；最后一句完成后保持打开，允许回看对白。
- 录音机：右侧桌面上的独立交互道具，打开可拖动的历史对话窗口，只显示已经完整播放过的句子。
- 设备：设备本体是库存中的道具；点击后打开对应小窗口，拖入原料，次日完成生产。
- 设备、旅行背包和顾客背包都是独立窗口，可同时存在；关闭按钮必须是对应窗口宿主的子节点，跟随窗口移动且只关闭自身。
- 门与睡袋：悬停显示白色轮廓，点击后进入相应交互。

## 5. 验收标准

- 任一小窗口都不覆盖整张经营场景，也不出现无意义空白区域。
- 12 件交易清单仍能在固定窗口中滚动查看，按钮和估值不会挤压商品列。
- 背包窗口拖动后，6×6 网格、物品和关闭按钮一起移动。
- 熔炉、炼药器、烹饪锅可同时打开；关闭其中一个不得清除其他设备的投放区。
- 客户 4 行格子不被人物对白或窗口拉伸破坏。
- 运行时文字、数字和状态没有烘焙进背景图。
