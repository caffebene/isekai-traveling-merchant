# 胡闹森林：无限探索与有记忆的荒诞遭遇

跨营业扩展见[森林委托与同行](森林委托与同行.md)：基础池增加受伤猎人（权重1），实际救助解锁营业回访；希尔薇委托以Boss掉落、实际成交、鹿王救场与战后对白推进，后续出发显示同行人物卡。保留无限探索、原事件间隔与战斗深度分离。

当前实现说明，2026-10-02。全局样式遵循[整体视觉与UI规范](整体视觉与UI规范.md)，玩家规则见[探索与战斗 Wiki](wiki/探索与战斗.md)，验证见[验收记录](../testing/胡闹森林验收.md)。本版替代七节点样板。

## 体验方向

旅商背着真实行李进森林。武器自动出手，玩家决定用物、整理收益和何时撤退。森林里的居民各有需求：宝箱饿了、蘑菇要保住房顶、青蛙轮流值不擅长的科、许愿井记着欠款。笑点从这些需求和玩家行为相撞产生。

探索没有距离、节点或首领通关限制。打赢古树只是又一次获得收益；可以继续直到死亡、主动返回或逃跑。难度随实际战斗次数增加，让资源和背包空间形成自然的撤退压力。阅读事件、整理和思考不消耗时间，没有强制限时。

荒诞成立的三个条件：先看见线索，再做动作，最后承担后果。首次遇见的角色不能引用不存在的共同经历；剧情变体改变选项或结果，不能只换一句招呼。所有回忆必须来自真实选择，不能把随机抽中的台词当成玩家历史。

## 遭遇节奏

`next_node()`无限生成下一次遭遇；总遭遇次数与战斗深度分开记录。普通随机抽取约45%尝试事件、其余战斗；事件冷却、待触发剧情和连续事件上限会改变实际比例，不能把45%当作最终事件频率。

- 自发事件池包含宝箱、蘑菇丛、青蛙、井、枯树、矿脉、篝火、蜗牛和受伤猎人，权重2:2:2:1:2:2:1:1:1。枯树/矿脉依据当前可用工具，猎人依据尚未实际救助进入候选池；法庭不在自发池。希尔薇交付后的鹿王战斗优先，既有后续票据保留。
- 同一自发事件至少隔3次遭遇；有已排队后续时不再次从自发池抽它。
- 最多连续2个事件，然后安排战斗；到期的古树催收属于战斗，可以直接出现。
- 后续不紧贴选择：宝箱追随隔2–4次，蘑菇诉讼隔3–5次，目击青蛙隔2次，井的催收隔3–5次。到期且满足条件的后续按时间优先，若碰到事件上限则稍后出现。
- 尚有官司时不生成新的蘑菇采集纠纷。每种后续只排一份，避免多次点击或多次拒绝挤满队列。

原有敌人轮换与战斗成长恢复：五类普通敌人、每3场的精英、每7场的古树首领；事件不参与层数计算。井的催收可以提前插入一次古树战斗。胜利始终进入战利品整理，保留继续和返回。

## 故事一：长腿宝箱，先有拒绝才有纠缠

**首次可能抽到三种实质剧情：**

| 剧情 | 可见线索 | 打开后的结果 |
| --- | --- | --- |
| 饿肚子 | 横在路上，强调“有点空”，对肚子问题含糊其词 | 等概率矿石＋防护药剂 / 咬伤12生命并吞1件行李 |
| 错写地址的快递 | 拖着湿送货单，收件人为“第一个背大包的人” | 矿石＋月光草，无咬伤 |
| 怕生练习 | 箱盖开缝，被看见又闭上 | 等概率矿石 / 紧张夹手损失6生命，无失物 |

饿肚子版对白依次展开：

> 旁白：一只宝箱横在小路上。你靠近时，它从箱底伸出两条腿。
> 宝箱：先别拔剑！我只是……有点空。
> 旅商：你说的空，是箱子里，还是肚子里？

选项：**伸手打开，赌里面有点好东西 / 递块面包，先让它松松口 / 让它走开，带着行李绕过去。** 面包消耗指定实体，稳定获得矿石与防护药剂；缺面包时禁用。

第一次拒绝只写“木头脚步没有走远”。再次相遇时才出现露在树外的脚，以及“我走开过了。走了两步，觉得咱们还有商量的余地”。连续真实拒绝3次后，下一次它才说“你已经赶我走3回了！我从那棵树追到这棵树……”。次数超过3时显示真实次数。

接受打开或喂食结束当前追随，拒绝计数归零。喂过面包会留下关系记忆；未来不在追逐中再遇到时，箱盖留着面包屑，主动交出新挖的矿石与药草。这样拒绝、信任和交易都有后续。

## 故事二：蘑菇丛 → 纠纷 → 证人 → 法庭

**前置遭遇先给玩家实际选择。**

“安静蘑菇丛”有两株月光草挤在菌帽间，俯身能听到小声数漏水；“搬家蘑菇丛”正在拖着草挪动，蘑菇提醒“房顶绑好了，别把上面的草扯掉”，荷叶下出现绿眼睛。这些线索在后续有用。

选项：**拨开蘑菇采草，省一点药钱 / 蹲下看看，听听那阵细声 / 避开菌丝，沿着小路继续走。**

采集等概率安全拿到两株草，或拿草时连菌丝掀翻小帽子。只有后者记录案由、采集地点、实际目击者和发生顺序，之后才排队法庭。安全采集、观察和绕开都不能凭空招来法官。

观察会实际扶正歪帽子。累计两次帮助后，未来蘑菇主动赠草，采集选项变成“接过它们推来的草，领这份心意”，不再触发毁屋。这条善意路线与索赔路线并存。

搬家纠纷中的荷叶绿眼睛就是青蛙；它会先于法庭回来。对白：

> 旁白：青蛙坐在荷叶上。你想起采草那天，也是这双绿眼睛躲在叶子下面。
> 旅商：你当时看见了吧？药草和蘑菇帽是怎么缠上的？
> 青蛙：看见了。不过本仙说话多，嘴容易干。

给一颗真实绯红果，它写证词；没有亲眼目击的普通青蛙不会提供这项服务。玩家也可以先求治伤或绕开，官司不会自动解决。

法庭开场认出当时的小帽子，读出真实案由，旅商承认那天的声音原来不是风。有证词才展示证词页，且上诉按钮相应改变。

| 动作 | 实际后果 | 后续记忆 |
| --- | --- | --- |
| 掏点赔偿，争取把这事了结 | 扣10G | 结案，清证词和待触发法庭 |
| 讲清采草经过，赌法官肯听 | 无证词成功/失败各50%；成功获30G，失败下一场敌人攻击×1.5向上取整 | 结案；判决只影响下一场战斗 |
| 递上青蛙证词，把经过讲清楚 | 上诉成功率75% | 证词消耗在结案中，不变成新物品 |
| 趁书记员打盹溜走，官司以后再说 | 无即时扣费 | 官司保留，隔3–5次再追；再次才有“左边已经补了菌丝”的回忆 |

纠纷让前面的小动作变成资源、叙事和未来风险。玩家能理解为什么被拦、能主动找证人、也能选择拖着麻烦走。

## 故事三：青蛙的奇迹，随机剧情改变它擅长什么

没有证人任务时，青蛙随机值“治伤科”或“器械科”，不连续重复同一剧情。治伤版贴假白胡子、把药涂在胡子上；器械版拿锈铁片敲荷叶，直言“会不会修是一回事，值不值班是另一回事”。先露出不可靠的线索，玩家再决定信不信。

- 治伤：亲一下，等概率全恢复 / 背包所有武器耐久−5。给果实稳定恢复15生命。
- 器械：把武器交给它，等概率所有背包武器耐久＋5 / −5；恢复不超过每件实际加工最大耐久，损失不低于0。果实仍可换治伤。
- 证人：只有搬家纠纷的真实目击者进入此版本，果实服务替换为写证词。

再次见面会按真实上一动作回应：上次绕开、给过果实、或相信过手艺；不会笼统虚构玩家曾被治好。选项的模糊风险来自角色表现，结果落地后才显示实际数值。

## 故事四：许愿井，拿到东西不等于交易结束

首次随机“饿肚子的井”和“回声当班”。饿井闻行李、让玩家先放下响的和重的；回声井慢半拍模仿玩家，提醒听错愿望的风险。

**投几枚金币，听听井底的回音 / 先拿愿望，答应以后补上报酬 / 把愿望留在心里，继续往前走。**

- 投币扣20G。饿井等概率药剂＋烤肉 / 卷走1件行李并吐废水；回声井等概率药草＋药剂 / 只吐废水，不额外失物。
- 赊愿立即获得力量药剂＋烤肉，井记下名字，结果对白中树枝朝账本伸过来，并排队古树催收。风险延后兑现，玩家先获得诱人的利益。
- 欠款期间再遇井，它翻出真实账册；原“赊愿”替换为“补上先前的报酬，试着撤掉追索”。付20G清账，取消催收；仍可再赌一个愿望，但旧债不会因此消失。
- 到期的催收由古树承担，或正常首领提前出现时兑现。它入场会说“你在井边签的账，该还了”，承接先前的树枝线索。首次攻击翻倍，再扣护盾；出手即结清，不论是否被盾全部挡住。以后不会重复收债。
- 返回、逃跑不能擦掉已经拿过愿望的欠款；下次出发继续认账。玩家可以在见到井时主动补款，也可以承受催收。

## 故事五：摇晃的枯树，工具开辟资源机会

旅行背包携带赤铜斧、辉铁斧或淬火斧且耐久至少1，枯树才可能进入遭遇池。橱柜里的工具、顾客的工具、已经耗尽耐久的工具均不算；资格随实际库存变化，不在出发时固定。携带工具增加一种可遇到的故事，不保证下一次一定采集。

两种剧情：小鸟抱着行李从开裂的树洞搬家，提醒别砍到床；打鼾的枯树震得粗枝掉木屑，允许取走枯枝却提醒别砸到谁。资源取自枯枝，不把战斗古树王的形象当作普通伐木目标。

| 选项 | 工具成本 | 结果 |
| --- | ---: | --- |
| 用斧头砍下粗枯枝，多带些木料 | 所选斧耐久−3 | 搬家版：各50%古藤木×2 / 古藤木×1＋绯红果×2；打鼾版：各50%古藤木×2 / 古藤木×1并损失6生命 |
| 只砍松动的小枝，留着斧刃赶路 | 所选斧耐久−1 | 稳定获得古藤木×1 |
| 把鸟窝留在原处，绕开这棵树 | 无 | 不损失耐久，无奖励 |

耐久剩1或2仍能遇见枯树，重砍禁用，小采集可用。两把以上满足该动作的工具时指定实际ID，只有该把损耗；耐久恰好用完后工具保留为损坏武器，战斗按原规则跳过。品质、词条和燃料改变的最大耐久不被采集改写。

## 故事六：路边矿脉，镐子也是探索决策

旅行背包携带赤铜镐或辉铁镐且耐久至少1时加入遭遇池，斧头或剑不能替代。矿脉随机为已经松动的裂壁，或叫得夸张的矿石：前者开场落石提示风险，后者声明“我叫得响，但不一定真的疼”，两者的深挖结果确实不同。

| 选项 | 工具成本 | 结果 |
| --- | ---: | --- |
| 用镐子凿进矿脉，赌里面料更好 | 所选镐耐久−3 | 裂壁版：各50%辉铁矿×2 / 辉铁矿×1＋赤铜矿×1并损失5生命；回声版：各50%辉铁矿×2 / 赤铜矿×2，无落石伤害 |
| 沿松动石缝敲一点，留着镐子赶路 | 所选镐耐久−1 | 稳定获得赤铜矿×1 |
| 不碰这些石头，带着工具继续走 | 无 | 不损失耐久，无奖励 |

采集没有暴击、吸血或行动力成本，也不推进战斗时间；它消耗的正是之后战斗要用的当前耐久。稀缺矿石能用于锻造、交易或背包相邻加成，收益通过现有战利品区选择带走。

## 故事七：倒班篝火，燃料能换一次真正的照顾

瞌睡火苗每点一次头就溅火星，抱怨玩家不睡它也要下班；正常值班火苗把柴排成值班表，提醒别拿水壶当枕头。没有付过柴时不会声称留了余火。

- 靠火休息：瞌睡版各50%恢复12生命 / 火星烫伤4生命；正常值班版稳定恢复10生命。选择文案随现场剧情改变。
- 添一段古藤木：消耗具体木料实体，恢复24生命（上限60），记录一份余火。背包缺木时禁用，不从橱柜取柴。
- 下次相遇才认出上回添柴的人，休息选项改为靠自己留下的余火，稳定恢复16生命，使用后清除该份余火；绕开会保留余火，再次添柴替换为一份新的余火，不无限堆叠。
- 绕开无变化，篝火记忆跨外出保留在当前会话。

这条路线将**带斧 → 取木 → 决定卖掉、锻造或添柴 → 恢复生命继续走**接进已有材料和背包循环，没有新燃料种类或额外清点页。

## 故事八：蜗牛收费站，荒唐收费也有相处后续

一只蜗牛把木杆横在小路上，宣称“过路要挪壳，挪壳算搬家，搬家总得有人付费”。另一剧情中，它刚把木杆搬来，就装成老收费站，称年头跟着壳走。首次不会认识玩家。

- 付点挪壳费：扣10G放行；老收费站给月光草×1，搬家版给绯红果×2，记录真实付费次数。
- 给一颗绯红果：消耗实际果实，放行并给草×1，记录喂食关系。
- 从壳边跨过去：各50%顺利通过 / 被突然伸出的触角绊倒损失4生命；没有付费或喂食记忆。
- 真正付过两次，或确实喂过果子，未来相遇才主动挪壳，并按对应行为致谢；付费按钮替换为免费的放行礼（月光草×1），绕开也不再绊倒。

同一角色的后来对白由实际动作控制。历史计数只记录支付成功或物品实际被消耗的选择，资金不足、无果实、重复点击均不能提前获得关系。

## 对白和选项的实际界面

右上窗口逐页展示角色名与对白；点击“继续”推进，最后一页再出现选择。通常2–3页，有证人或再次逃诉才增加相应页。对白不是长度固定的说明书，每页服务于环境线索、角色需求或玩家回应。

按钮只写动作和模糊可能影响；没有按钮下方说明行，不显示概率、伤害预测、奖励清单或未来精确惩罚。金币总额仍可见，缺物/缺钱禁用并给必要错误反馈。玩家应从现场线索作决定，而非比较几条数值公式。

点击即锁定，播放1.4秒结果动作，保留一页剧情结果，点击“继续”即进入战利品区；没有行李清点、数值清单或“收拾行李”对白页，生命与物品变化通过实际界面反馈，原拖放、双击、Ctrl收纳和未拾取确认都保留。不会在选项旁提前揭晓随机抽签。

## 画面与动作

只有一张不透明静态森林背景：`forest-distance.png`。道路、雾、树木和月光已在同一图片中，不挂载3D层，不前进滚动，不循环换景，不旅行缩放。旧分层素材仅保留历史来源。

商人在左下前景，敌人和事件居民在右侧；人物六姿态、武器出手顺序、蓄力预兆、受击、护盾、滑稽退场与奖励飞入继续使用。前进0.475秒表现商人行走，背景轻度虚化；抵达后角色入场0.175秒，背景恢复清晰。完整前进与入场共0.65秒，为原时长的一半；角色、背包和按钮不参与虚化。视觉停顿100毫秒不停止实际战斗计时，震动只作用于角色与场景效果，背包和按钮稳定。

新增蘑菇丛透明角色素材区别于戴法官帽的蘑菇法庭。UI沿用深底、棕金边框和金色标题；不把对白或提示烘焙进美术。

## 记忆范围和实现接口

`TradeState.forest_memory`保存在当前游戏会话，不新增磁盘存档。它记录真实见面次数、最近剧情/动作、宝箱追随与喂食、蘑菇帮助与未结案由、证词、井欠款、篝火余火、蜗牛付费/喂食及待回归队列。最近故事历史最多64条，长期事实使用计数/字段，无限探索不无限增加历史内存。

每次新外出重置遭遇数、战斗深度、生命和本次判决；世界关系、未结官司和欠款继续保留。战败仍按隐藏夹层规则保物；角色没有声称看见玩家未做的行为。

状态流：`idle → event → event_resolving → event_result → event_loot`，或`idle → ready → battle → victory/defeat`。胜利与事件整理可持续返回下一次遭遇，没有complete状态。

- `ForestEvents.eligible/build/outcome`和`forest_extra_events.gd`：根据世界事实决定资格、剧情/对白/可用选择，支持带权结果。
- `next_node`：清旧战利品，处理到期后续，再抽自发遭遇或战斗；`route_index`只统计次数。
- `choices_available/current_dialogue/advance_dialogue`：控制对白和结果阅读；未读完不能选择。
- `choose_event(option_id,item_id)`：校验真实ID、区域、归属、类别与资金后先锁状态，再统一结算一次；随机失物只命中玩家背包，空包安全跳过。
- `finish_event`：只从演出进入结果阅读，重复调用无副作用，不能覆盖致死后的defeat。
- `presentation`：仍传真实攻击者、武器ID、实际伤害、护盾吸收和用物结果。

事件损失不受隐藏夹层保护；事件致死执行现有战败处理，不发该次奖励。判决下一场开战前生效、胜利/死亡/逃跑后清除；井债只在实际首领第一次出手或主动还款时结清。战斗中仍不能整理背包，允许主动用物与逃跑。

设计保留桌面1600×900逻辑画布与1440×810窗口，无新增动作闪避、区域地图或物品体系。完整生成来源见[美术批次](../../assets/exploration/boisterous/generation.json)。

开战立即执行一次真实自动攻击；选择首把可用武器或徒手回退，消耗耐久并发出原有攻击表现信号。后续从完整冷却开始，轮换到下一把武器；敌人仍在原3秒周期出手，重复开始操作不会追加攻击。

工具选项复用`choose_event(option_id,item_id)`：选择时重新校验玩家归属、背包区域、工具类别及够不够本次耐久；锁定结算后扣对应实体耐久，不删除工具。`event_items`统一取得献祭或工具候选，`tool_id/tool_key`传递真实采集工具，复用背包亮边、挥击、场景反应和材料飞入。
