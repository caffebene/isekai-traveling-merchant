# 道具生成提示词

全局风格以 [整体视觉与UI规范](整体视觉与UI规范.md) 为唯一依据；本文件只定义道具类别、视角、透明背景与尺寸分支。

本文件是经营页、探索页和设备栏道具图标的统一生成参考。生成或替换道具图片时，先选择对应类别的提示词，再补充物品本身的形状、颜色和占格尺寸。最终资源必须放入 `assets/`，并由 `scripts/item_art.gd` 统一加载。

## 通用要求

- 使用内置 `imagegen`，输出真实透明背景的 RGBA PNG。
- 只生成一个独立物品，主体居中，保持清晰剪影；不生成文字、Logo、水印、场景、人物或手。
- 图标在 48–96 px 的游戏显示尺寸下仍要能认出主要特征。
- 目标画布按 96 px/格处理，主体最大填充约 94%，保留透明安全边距。
- 处理时去除 alpha 小于 12 的生成雾边，不把网格、描边或 UI 文字烘焙进 PNG；运行时描边由 `scripts/item_art.gd` 统一绘制。
- 生成前确认未旋转占格尺寸；长剑、材料、食物、设备等按照 `assets/items/generation.json` 和本项目物品图鉴的尺寸输出。
- 武器画布尺寸是外接边界，不代表必须填满所有格子。镐保留横向镐头和居中竖柄的T型，斧保留头部与单列柄；透明边侧对应可用空格。替换图片时同步核对 `TradeState.FOOTPRINTS`，不得把柄两侧补成实心矩形，不能只改图片而保留冲突的占格轮廓。

## 普通异世界道具

月蚀树心沿用本分支：单颗深棕木节心、浅蓝月牙纹与一片小银叶，正面三分之四自然材料，禁止改成霓虹水晶；2×2、192×192，既有alpha清理与94%留白规则。生成记录`assets/items/story-generation.json`，使用`tools/import_unified_art.gd`原导入器，运行PNG由`item_art.gd`统一加载。

适用于矿石、草药、果实、食物、药剂、背包等自然手工材质道具。当前批次为 `ordinary-fantasy-v2`。

```text
Standalone ordinary otherworld fantasy game item icon; clean Japanese anime 2D illustration using large graphic color blocks, stable crisp linework, grouped shadows, and a few restrained highlights; natural handmade materials appropriate to the object, such as glass, cork, brass, cloth, leather, wood, baked bread, raw boneless meat, cooked steak, stone, ore and plant matter; clear readable silhouette at gameplay size; centered single object; genuine transparent alpha background; no text, no logo, no watermark, no grid.
```

根据物品类型补充材质和辨识特征，例如：矿石的晶纹、药剂的液体颜色、草药的叶片层次、面包的烘烤切面、肉类的无骨肉块轮廓。避免为了增加细节而加入密集纹理、雾边或无关装饰。

```text
Avoid: photorealistic photography, cyberpunk, sci-fi, modern industrial machinery, Y2K hardware, excessive neon, medieval architecture, dirty texture, grain, film grain, painterly texture, watercolor, sketch, blur, depth of field, pixel art, text artifacts, watermark, extra objects, characters, hands, scenery.
```

## 都市工业设备道具

适用于炼药器和工作台等设备图标。设备图标采用总规范的石墨金属、暖白护板与克制状态色，不使用普通道具的木材、黄铜器皿或中世纪锅炉造型。

```text
Otherworld merchant workshop machine item icon with a grid-matched silhouette, clean non-pixel Japanese anime hard-surface 2D game asset with large graphic planes, one grouped shadow per material, dark graphite and gunmetal panels, crisp cel-shaded planes, stable hard-surface linework, restrained cyan status lights and orange safety accents, compact modular machine with large warm-white corner guards and a few simple panel seams, one isolated object, centered, genuine transparent alpha background, no text, no logo, no watermark.
```

### 视角与构图（必须遵守）

设备必须使用**完全正面正交视角**：机器正面正对镜头，正面居中且左右对称；只显示正面，不显示顶部、左侧或右侧面；所有外轮廓边保持水平或垂直，不使用等轴、三分之四、透视汇聚或倾斜镜头。画布比例必须与物品占格一致：工作台为 `4:4` 正方形，炼药器为 `3:4` 纵向矩形；不能用正方形素材拉伸代替 `3×4` 设备。

Front-facing square 4:4 fabrication machine, orange illuminated processing hatch centered on the front panel, restrained orange safety markings, cyan horizontal status bars, graphite black and silver metal, symmetrical large corner guards, fully orthographic head-on view, no visible top or side faces.

## 锻造武器与矿石图片批次（2026-10-02）

赤铜矿、废水及赤铜/辉铁/淬火系列武器必须使用独立透明PNG，不再接入旧SVG或程序绘制道具。具体生成提示词、原始图片路径、占格与最终路径见 [批次记录](../../assets/items/workbench/generated/generation.json)；提示词清单见 [prompts.json](../../assets/items/workbench/generated/prompts.json)。本批沿用普通异世界道具分支，由内置imagegen逐件生成。

- 赤铜：自然铜红金属与暖色反光；辉铁：冷银蓝金属；淬火：深钢、明亮刃缘与少量青铜金色结构。三类保持清晰的材质和颜色区别。
- 武器完整直立、正面、不倾斜、不缩短透视；剑尖向上、握柄向下，斧头和镐头在上、木柄向下。暗皮革与木材为自然手工材质，不使用科技零件、霓虹、魔法光晕或过量花纹。
- 所有长剑均采用相同竖直中轴、水平护手和完整轮廓，不带剑鞘或肩带；不复用历史倾斜长剑。旅人长剑为暖银钢、黄铜护手、菱形剑首和棕皮柄；辉铁剑为冷银蓝钢、少量金色剑身结构、圆形剑首和深棕皮柄。两张重绘的完整提示词与原始图片路径见 [直剑生成记录](../../assets/items/workbench/generated/straight-swords-generation.json)，运行资源为同目录的 `sword.png` / `iron_sword.png`。
- 矿石用自然碎岩轮廓与铜色矿脉；废水为灰橄榄色浑浊液体、少量沉淀与软木塞，不渲染成发光药剂。
- 目标尺寸按真实占格：赤铜矿192×192，剑192×576，斧288×480，镐384×480，废水96×288。使用已有 `tools/import_unified_art.gd` 完成alpha阈值12、等比缩放与94%填充；不得拉伸。
- 新道具必须先生成并接入共享 `ITEM_TEXTURES`。禁止用SVG或程序几何图形充当正式道具资源；窗口、网格、状态徽标及配方箭头仍使用共享程序组件。

## 武器品质轮廓规则

同种武器五档品质共用正式透明RGBA PNG，品质光边由运行时按alpha轮廓绘制，不生成五套重复图标。正面视角、占格比例和现有正负面提示词保持原规则。生成分支禁止烘焙白／绿／蓝／紫／金品质轮廓、外部光晕或品质文字；材质自身高光保留。运行时品质色与强度以《整体视觉与UI规范》的武器品质视觉为准。
