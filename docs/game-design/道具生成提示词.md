# 道具生成提示词

本文件是经营页、探索页和设备栏道具图标的统一生成参考。生成或替换道具图片时，先选择对应类别的提示词，再补充物品本身的形状、颜色和占格尺寸。最终资源必须放入 `assets/`，并由 `scripts/item_art.gd` 统一加载。

## 通用要求

- 使用内置 `imagegen`，输出真实透明背景的 RGBA PNG。
- 只生成一个独立物品，主体居中，保持清晰剪影；不生成文字、Logo、水印、场景、人物或手。
- 图标在 48–96 px 的游戏显示尺寸下仍要能认出主要特征。
- 目标画布按 96 px/格处理，主体最大填充约 94%，保留透明安全边距。
- 处理时去除 alpha 小于 12 的生成雾边，不把网格、描边或 UI 文字烘焙进 PNG；运行时描边由 `scripts/item_art.gd` 统一绘制。
- 生成前确认未旋转占格尺寸；长剑、材料、食物、设备等按照 `assets/items/generation.json` 和本项目物品图鉴的尺寸输出。

## 普通异世界道具

适用于矿石、草药、果实、食物、药剂、背包等自然手工材质道具。当前批次为 `ordinary-fantasy-v2`。

```text
Standalone ordinary otherworld fantasy game item icon; clean Japanese anime 2D illustration using large graphic color blocks, stable crisp linework, grouped shadows, and a few restrained highlights; natural handmade materials appropriate to the object, such as glass, cork, brass, cloth, leather, wood, baked bread, raw boneless meat, cooked steak, stone, ore and plant matter; clear readable silhouette at gameplay size; centered single object; genuine transparent alpha background; no text, no logo, no watermark, no grid.
```

根据物品类型补充材质和辨识特征，例如：矿石的晶纹、药剂的液体颜色、草药的叶片层次、面包的烘烤切面、肉类的无骨肉块轮廓。避免为了增加细节而加入密集纹理、雾边或无关装饰。

```text
Avoid: photorealistic photography, cyberpunk, sci-fi, modern industrial machinery, Y2K hardware, excessive neon, medieval architecture, dirty texture, grain, film grain, painterly texture, watercolor, sketch, blur, depth of field, text artifacts, watermark, extra objects, characters, hands, scenery.
```

## 科幻设备道具

适用于炼药器和工作台等设备图标。设备图标沿用交易页的绝区零工业 UI 气质，不使用普通道具的木材、黄铜器皿或中世纪锅炉造型。

```text
Futuristic urban action RPG machine item icon with a grid-matched silhouette, polished hard-surface 2D game asset, dark graphite and gunmetal panels, crisp cel-shaded planes, stable hard-surface linework, restrained cyan status lights and orange safety accents, compact modular machine with reinforced corner bolts, vents, panel seams and machined bevels, one isolated object, centered, genuine transparent alpha background, no text, no logo, no watermark.
```

### 视角与构图（必须遵守）

设备必须使用**完全正面正交视角**：机器正面正对镜头，正面居中且左右对称；只显示正面，不显示顶部、左侧或右侧面；所有外轮廓边保持水平或垂直，不使用等轴、三分之四、透视汇聚或倾斜镜头。画布比例必须与物品占格一致：工作台为 `4:4` 正方形，炼药器为 `3:4` 纵向矩形；不能用正方形素材拉伸代替 `3×4` 设备。

```text
Front-facing square 4:4 fabrication machine, orange illuminated processing hatch centered on the front panel, orange warning chevrons, cyan horizontal status bars, graphite black and silver metal, symmetrical reinforced corner plates and vents, fully orthographic head-on view, no visible top or side faces.
```

## 项目资源与验收

- 普通道具生成记录：`assets/items/generation.json`。
- 普通道具运行目录：`assets/items/candidates/generated/`；旧批次归档在 `assets/items/archive/`。
- 当前设备图标：`assets/items/workbench/workbench-machine.png`、`assets/items/workbench/alembic-machine.png`。
- 生成完成后检查 RGBA 透明角、主体是否贴边、正面是否对称、画布宽高比是否匹配占格，以及在物品栏小尺寸显示时是否仍能辨认。
