# 顾客阵营与故事

2026-10-03。参考[《深空当铺》角色与派系](https://probablystolen.gamewikistation.com/zh-cn/characters/)中人物所属群体、交易牵出后续人物的结构；人物、台词和支线均为本项目原创。复用原交易、议价、关系、城市行情、顾客背包、逐字对白与手机历史。

## 柜台背后的五个群体

| 阵营 | 人物 | 生活与矛盾 | 已实现的故事结果 |
| --- | --- | --- | --- |
| 森林守望 | 希尔薇、绫叶、奥林 | 希尔薇找母亲走过的旧路；绫叶为伤者备药；奥林因为伤腿不再逞强深入森林 | 救助猎人解锁顾客；希尔薇成交后提出树心委托，接既有Boss、救场与同行主线 |
| 炉桥工班 | 布洛克、赫伯特 | 卸货挣钱与停井修支架的冲突；工头不愿让夜班冒险 | 收矿引荐工头，供燃料后修好支架，工头开始可能出售备用辉铁剑 |
| 南门街坊 | 米菈、伊芙 | 客栈赶饭点；晚归工人、老人和孩子缺一顿熟饭 | 客栈供饭引荐互助会，继续供饭后添桌办晚饭，后续可能带防护药剂来售 |
| 巡夜队 | 莱昂、诺拉 | 押货剑士的开销；队长带新人巡夜，旧装备已经不堪用 | 向诺拉供武器凑齐新人装备，后续可能出售旧库辉铁剑 |
| 夜路行会 | 阿雀 | 熬夜跑腿、货主不肯露面、车卡在坡底；正经谋生也会被当成小偷 | 向阿雀供力量药剂帮推车，后续增加古藤木带货权重 |

阵营不是善恶标签，没有自动敌对、违法判定或阵营价格倍率。人物的生活处境通过对白和真实供货结果表现。一次来访至少成交一次，所属阵营交情+1，最多10；同次来访分批成交不反复加阵营交情。原个人关系仍按每次成交+1、最多5运行；个人关系达到2后可闲聊本城近期新闻。阵营交情提高同阵营来访权重，不直接加战斗能力。

## 随机来客

首次运行、换客和次日开门都从已解锁人物中抽取；不固定每日希尔薇，也不再四人轮换或插入猎人。与上一位不同。基础权重：希尔薇/布洛克/米菈为3，阿雀为1，其余为2。森林、街坊、巡夜人物在风栖镇+2；工班、夜路人物在铁砧城+2。阵营交情每3点增加1权重，最多+2；树心主线处于委托/交付/救场阶段，希尔薇额外+2。

不是抽一次就永远失联：离上次抽中达到20次时进入久未见名单，按最久未见优先到访。十人池的等待上限按30次换客验收。刚解锁者可立即进入抽取，不保证下一位必来；解锁不删除或重排当前顾客货物。休息、返回与旅行保留事实，城市只改概率，不禁止外地人来访。

## 真实交易推进的小故事

| 起点 | 累计实际成交要求 | 一次性回应与结果 |
| --- | --- | --- |
| 布洛克带矿 | 买入辉铁矿/赤铜矿合计3块 | 布洛克提出介绍赫伯特；工头加入随机池 |
| 赫伯特修支架 | 卖给工头古藤木/粘液合计3份 | 修完剩余支架；后续货品池加入辉铁剑 |
| 米菈备饭 | 卖给米菈面包/烤肉合计3份 | 提到找饭的伊芙；互助会加入随机池 |
| 伊芙办晚饭 | 卖给伊芙面包/烤肉合计3份 | 添桌继续办饭；后续货品池加入防护药剂 |
| 诺拉换装备 | 卖给诺拉武器合计2件 | 新人装备齐了；后续货品池加入辉铁剑 |
| 阿雀帮推车 | 卖给阿雀力量药剂合计2瓶 | 车能上坡了；后续古藤木权重从1增加为3 |

含混合交易，严格依据成功批次中的真实物品；失败、无意愿、放柜台、撤回和空柜台重复点击不计。不是额外免费奖励，不会重复给道具；解锁后也仍按普通行情与议价成交。分多次供货可累计，完成回应只播一次。有关支架、晚饭、药瓶的熟客回顾，还需要对应供货事实，不因为买走一包草就凭空声称曾给对方药。

## 希尔薇开口的时机

到场：正常材料生意，不含树心需求。首次与她成功交易后，设置 `request_available`，立刻沿用原对白播放：

> 谢谢，材料我收下了。有件事想托你帮忙，你最近还会进森林吗？
>
> 你要是从月蚀古树王那里拿到月蚀树心，能带回来卖给我吗？
>
> 我一直没找到母亲走过的那条路。听说树心能照出路上的记号，我想试一试。

真实播放或揭示委托页后才进入 `requested`。只成交还没听到需求，不会提前让Boss掉委托物；中途送走她，允许下次补说。未成交时浏览旧文本不能绕过门槛。树心必须之后卖给她实际成交才推进鹿王主线。主线其余边界仍见[森林委托与同行](森林委托与同行.md)。

## 台词和实现约束

先写人要做什么、手头有什么麻烦，再写商品。米菈赶着回锅边，布洛克抱怨箱扣，绫叶会看瓶底，阿雀怕被误认为小偷。日常成交用一页完整的回应；委托和故事进展用2–3页。不用全员同一套“请将合适物品放上柜台”。不宣读剧情状态、解锁数值或系统操作。随机开场、符合事实的回头话、成交话、一次性故事结果与熟客闲聊各自有来源；手机保留已播放的姓名、身份与阵营。

成交回应区分玩家买入、出售和混合买卖。顾客卖货才说收到钱，收购药剂才说收好药；混合交易同时回应两边货物。不额外编造包裹、衣服、食物份数或交付动作。例如阿雀收购药剂时说“药剂我收好了，谢谢。这趟路上正好用得着。”；绫叶混合买卖时说“药剂我收下了，药材你拿好。谢谢。”。一次性引荐直接说明是谁、需要什么、接下来会做什么。

`customer_roster.gd`存人物数据、抽取、随货、实际成交计数、一次性回应及闲聊；`TradeState.customer_memory`存抽取历史、交情、供货与解锁。`shop.gd`保留经营入口和所有原交互，首次/换客/开门使用统一抽取，成功结算后调用故事回应。`forest_story.gd`控制成交门槛与委托页读取。沿用无持久化存档范围。美术来源见[生成清单](../../assets/customers/faction-generation.json)。
