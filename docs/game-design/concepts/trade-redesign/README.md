# 交易页面优化参考

当前画面相似感主要来自正中窗口顾客、横向柜台、底部中央大库存、右上小交易窗的组合。此次重做空间构图与信息层级，而非只调整配色。

| 方向 | 核心变化 | 优势 | 取舍 |
| --- | --- | --- | --- |
| A 侧开的旅商车 | 左侧顾客、中央交易、右侧货箱，户外侧开商车 | 角色互动、商车氛围和操作清晰度兼顾；优先推荐 | 需要重绘商车背景，并重新布置库存 |
| B 旅商账簿 | 库存与议价成为账簿左右两页 | 报价集中、经营感强、方便扩展委托与记录 | 场景沉浸感减少 |
| C 营地摆摊 | 户外营地、货毯交易、固定侧边商谈栏 | 旅行身份突出，与现有正面车内构图差异大 | 环境美术与空间组织改动较大 |

三版均为内置 image_gen 生成的视觉方向参考，未接入游戏。文字、网格形状和容量均需在落地时由程序准确绘制。继续复用现有 TradeState、物品占格、旋转、拖放、议价及结算逻辑。

建议将交易物品与报价控件聚合，弱化空网格、放大商品与主要动作。买入与卖出、交易后待收取、顾客资金不足等状态仍沿用现有行为，选定方向后补齐状态设计。
