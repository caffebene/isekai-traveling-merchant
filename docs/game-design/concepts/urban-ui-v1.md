# 《异世界旅商》整体视觉与 UI 规范

版本：`urban-fantasy-v1` · 2026-10-02 · 状态：当前唯一全局风格依据。

新页面、组件、美术和生成提示词必须先遵循本文件。场景与道具提示词只补充各自的题材、视角、尺寸，不另设色板、字体或 UI 风格。旧概念稿、旧生成记录和截图只用于历史追溯。若规范与实现不一致，先修正对应实现并更新基准截图，不能另建平行规范。

## 1. 项目定位

桌面 Godot 游戏，1600×900 逻辑画布，1440×810 默认窗口，`canvas_items` 等比缩放。核心循环是空间库存、实体柜台交易、议价、跨日加工、城市行情、商车改装与野外探索。保留全部既有规则、物品 ID、占格、容量、配方和快捷操作。

## 2. 视觉关键词

复古都市、奇幻旅商、清晰色块、粗体标签、实体操作。

## 3. 整体视觉方向

“复古都市 × 异世界旅商”。现代都市商车与工业设备、奇幻人物与自然材料、野外森林属于同一世界。参考《绝区零》的形体、图形表达和生活化都市气质，参考《深空当铺》的柜台、空间库存与设备交互；不照搬角色、标志或完整界面。

所有美术采用日式动画画法：稳定轮廓、每种材质一组底色和成组阴影、少量高光。细节集中在物品和人物的辨识特征，按实际游戏尺寸判断密度。暖白内饰、石墨金属、布料与自然材料可以并存。环境可改变色温与色板，UI 不随页面更换材质、字体或状态色。禁止像素风与动画风混用，禁止依靠模糊、噪点、写实锈蚀、密集划痕或过量发光制造材质。

## 4. 色彩规范

| 语义 | 色值 | 使用规则 |
| --- | --- | --- |
| 背景 | `#15191E` | 控件深底、管理页面内层 |
| 面板 | `#222830`，不透明 | 所有窗口与对白底板 |
| 次面板 | `#2C333D` | 交替行、卡片与悬停后的次按钮 |
| 标题条 | `#F2EEE5` / `#15191E` | 暖白底、石墨色粗体标题 |
| 主文字 | `#F2EEE5` | 名称、数值、正文 |
| 次文字 | `#AAB2BA` | 表头、次信息、短状态 |
| 外框 | `#69737E` | 1 px 窗口边界 |
| 分隔 | `#3B4550` | 内部弱分隔，不再嵌套白框 |
| 主操作 | `#FF6B35` | 当前主要操作、选中交易标签、少量标题标识 |
| 状态 | `#55C7CC` | 生效、护盾、有效投放、辅助状态 |
| 错误 | `#E56B6F` | 生命、拒绝、无效投放、错误 |
| 禁用 | `#727B85` | 禁用文字与弱化状态 |
| 网格底/线 | `#1A2027` / `#37424D` | 24 px 库存网格 |

橙色主按钮使用深色文字；其他控件使用米白文字。主操作悬停只提高明度，不能跳为青色。行情涨跌以橙/青加正负数表达；不能仅靠颜色传达状态。物品材质与战斗类型色不必染成 UI 橙色。

## 5. 字体规范

统一无衬线，回退顺序为 PingFang SC、Noto Sans CJK SC、Microsoft YaHei。使用 `PopupSkin.font()` / `PopupSkin.theme()`；不再建立宋体标题支线。

| 层级 | 逻辑字号 | 使用场景 |
| --- | ---: | --- |
| 页面标题 | 24 | 行情、改装、探索、配方名称 |
| 窗口/模块标题 | 20 | 交易、设备、历史、对白姓名 |
| 正文/操作 | 16 | 对白、按钮、主要交易数据 |
| 次信息 | 14 | 表头、类别、状态、历史署名 |
| 密集物品角标 | 9–11 | 24 px 网格内短战斗标记；完整信息须在悬停可读 |

金额列使用固定宽度、右对齐；还价输入居中。禁止缩小整段正文来掩盖溢出。必要规则可以保留，显而易见的操作说明、重复提示和装饰性句子不显示。

## 6. 页面布局规范

- 固定场景、连续柜台与主库存作为经营页中心。顾客可见区优先于浮窗；普通背包和设备不添加全屏遮罩。
- 日期/城市/金币位于左上；行情与改装紧随其后，右上保留顾客背包、帮助与营业状态。
- 顾客背包默认 `(24,104)`，24×4 格；旅行背包默认 `(24,320)`，容量读取状态；交易清单默认右侧 `(1180,354)`，宽 400、列表滚动，内容增多时窗口限制在画面内。
- 对白默认 `(960,104,360,170)`；历史窗口默认 `(1180,292,320,540)`，可拖动。
- 工作台默认 `(280,492)`、炼药器 `(816,470)`、烹饪锅 `(24,600)`，尺寸由既有网格决定。并行打开互不关闭，窗口遮住底层交互时不允许穿透。
- 旅行背包的组合效果附在相邻面板，保留真实数值；扩容、长武器、多条效果和长交易单须检查溢出。
- 行情/改装/确认/配方属于管理或决策模态层，使用统一深色遮罩；普通交易、背包、设备不使用遮罩。
- 探索背包与战利品位于战场上方两侧，生命卡与主要操作位于下方；角色、怪物和旅途分层场景继续复用原站位与过渡。
- 基础间距 4/8/12/16/24 px。窗口拖动在 1600×868 内限制边界，关闭按钮热区至少 32×32；普通按钮 32/40 px，探索既有 52 px 大按钮保留。

## 7. 组件规范

运行时唯一样式入口为 `scripts/popup_style.gd`。兼容旧的 PAPER、INK、DARK、WALNUT、BRASS 名称，但新实现使用 TEXT、BACKGROUND、FRAME 等语义名称。

- 窗口：1 px 外框、8 px 左上/右下切角、3 px 偏移的轻阴影；48 px 暖白标题栏、石墨色粗体标题、短橙色边标与宽窗右侧双斜线。内容区使用不透明深色，避免场景透入干扰阅读。复用 `draw_window()` / `window()`；无标题的信息卡使用 `panel()`。不增加材质纹理和螺钉装饰。
- 按钮：粗体文字，主按钮橙色、次按钮近黑色，2 px 小圆角与克制的底边压印；复用 `button()`，默认/悬停/按下/禁用/键盘聚焦齐全；`close_button()` 统一关闭热区。主按钮不根据页面换色。
- 网格：复用 `draw_grid()`，逻辑格始终 24 px，物品占格不受外观改版影响。库存只在需要操作时绘制格线。
- 卡片/列表：改装卡片使用单色货架、保护锁与锅具图形标识，图形由共享样式入口绘制；面板底、弱分隔，名称/主要数值优先；商品金额右对齐。长列表使用滚动容器，图标保持完整缩放而非裁切。
- 确认/帮助：共用标题和按钮，正文宽 550 px 自动换行，窗口高度按正文计算为 224–492 px；操作固定在面板底部，避免短确认留下大块空白。
- 对白/历史：程序绘制面板，姓名与正文独立布局；保留逐字、翻页、已完成句历史。旧 `dialogue-frame.png` 不参与运行。
- 悬停：统一水平深底提示、1 px 灰框和短橙色边标。场景物只显示名称；道具显示必要属性与操作，按文本动态增加高度。
- 血条/护盾/冷却：深底、平面填充；数值配合颜色。战敗只显示结果与实际损失规则，避免重复失败说明。

## 8. 交互规范

保持拖放、R 旋转、右键/Esc 取消、双击快捷操作、混合买卖、还价、跨日加工、战利品快捷拾取。主按钮按下轻微缩放，120 ms 恢复；悬停 120–180 ms。现有角色到场、卷帘门与森林过渡按玩法节奏保留，不强行缩短。

窗口层级：经营画面 < 独立窗口关闭控件 < 交易清单 < 历史 < 管理/确认/配方 < 探索 < 当前页道具悬停。覆盖区的绘制与点击必须一致；不能出现关闭控件浮到覆盖窗口上方。未拾取物品离开、营业结束等既有确认保留。正常操作不增加成功 toast，错误与必要状态保留。

## 9. 图像生成规范

共享风格前缀：

```text
Clean Japanese anime game art, deliberate large graphic color planes, stable crisp continuous linework, one grouped shadow and at most one restrained highlight per material, readable silhouette at gameplay scale, sparse internal detail concentrated on identity features, warm light and cool grouped shadows, smooth clean surfaces, retro urban and otherworld merchant setting.
```

反向限制：pixel art, photorealism, dirty texture, grain, scratches, stippling, all-over microdetail, excessive neon or bloom, blur, text artifacts, logo, watermark, baked UI.

场景构图、人物身份和道具视角分别追加，不能通过复制历史完整提示词覆盖本规则。普通材料保留自然材质；工业设备使用正面正交视角与匹配占格的画布，橙色加工舱/紫色炼药舱区分功能。透明资产输出 RGBA，96 px/格，alpha <12 清理，主体最大填充94%。运行时文字、网格、价格和状态不得烘焙。

执行分支见 [主世界提示词](../玩家主世界画风提示词.md) 与 [道具提示词](../道具生成提示词.md)。当前资产判定见 [美术资源](../美术资源.md)，基准与验收见 [统一改版验收](../../testing/统一UI改版验收.md)。

## 10. 后续维护

新增页面先使用已有组件；新增状态先检查已有语义 token；仅确实缺少的能力才扩展共享入口。任何风格变化同次修改本文件、样式代码、对应生成分支及实际游戏截图。Wiki 同步玩家可感知的布局/入口/操作变化。历史概念不参与当前设计决策。
