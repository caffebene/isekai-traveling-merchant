# 玩家主世界画风提示词

全局风格只由 [整体视觉与UI规范](整体视觉与UI规范.md) 定义。本文件补充场景和人物生成约束，不定义另一套 UI。

## 当前方向

旅商世界的日式动画画法。都市商车、工业加工设备、奇幻顾客与自然材料共存。采用清晰的日式动画画法；街区有生活感，森林有自然环境色。当前 UI 按用户物品卡参考采用深底棕金账册风格；场景不生成界面、文字或窗口，不再以《绝区零》作为风格依据。

## 构图约束

- 当前经营场景保留独立内景、窗外城市、顾客和交互道具分层。
- 柜台保持连续台面；30×12 橱柜定位和自由物理台面由程序定义，不生成柜台格子。
- 门、卧铺、电脑、手机、铃和关门器的轮廓匹配各自点击蒙版；替换时同步校对投放区与碰撞。
- 森林使用单张不透明静态背景，完整绘入道路、树木、月光与地面；不制作前进换景或循环叠层，UI控件沿用全局材质。

旧概念与历史生成记录只用于追溯，不覆盖当前规范。

清晰日式动画画法、蓝绿月夜森林、稳定大色块与成组阴影。单张不透明横向背景包含全部森林环境，中央道路保持安静；旧道路、舞台和前景叠层归档，不参与运行。角色为独立透明图，不生成UI、文字、地面或投影。

商人保持棕发、绿披风、米白袖、棕背包、青色卷毯与黄铜提灯的身份，六姿态分别生成独立资源，朝右的侧后方半身构图；禁止相邻姿态串入同一帧。事件角色分别为长腿宝箱、自然蘑菇丛、蘑菇法庭、浮叶青蛙与吐槽井。敌人朝左；史莱姆叶冠、宝箱盖与古树王树冠通过运行时分部绘制产生次级运动。

完整提示词、生成来源与最终文件见 [胡闹森林批次](../../assets/exploration/boisterous/generation.json)。透明图只允许alpha阈值清理与等比导入，保持轮廓和颜色，不把界面烘焙进图片。
