# 玩家主世界画风提示词

这是玩家主世界场景的默认美术方向。后续生成主世界、城市街区、探索地点、室内空间和相关背景时，优先复用本文件的风格提示词；场景构图、功能留白和可交互区域另行写入各场景提示词。

## 风格方向

绝区零风格的现代都市商业街场景，潮流日系二次元游戏美术，轻度 2D 日系动漫风格，复古未来主义都市设计，充满生活气息的街区。

强烈的街头潮流设计语言，融合 Y2K、复古录像带、90 年代街机文化、现代东京街区和漫画平面设计元素。广告招牌可以使用夸张字体和图形设计，但不过分堆砌霓虹。整体年轻、时髦、活泼、有生活感，像可自由探索的二次元都市游戏街区。


## 正面提示词

干净的日式动画游戏美术，以大色块组织画面。每种材质只用底色、成组阴影和少量高光，通过形体表现体积。细节集中在辨识特征，其他区域保持安静。保留清晰轮廓，不靠模糊制造简洁感。

## 使用约定

- 保持清晰剪影、稳定线稿和强烈色彩分区，避免用密集纹理堆出材质。
- 都市招牌、海报和贴纸优先使用图形化信息；若不是专门的文字资产，避免生成可读文字、品牌 Logo 或水印。
- 交易、背包和探索等 UI 需要的网格、数字、按钮和文字由程序绘制，不烘焙进背景图。
- 具体场景可以替换色板和环境元素，但不得削弱大色块、成组阴影、少量高光和生活化都市设计这几个核心特征。
- 当前交易车布局约定：底部橱柜与中央储物组件组成一个居中的连续区域，整体宽度约占画面宽度 60%；柜体底边直接接地，不增加底层、底座或踢脚板。
