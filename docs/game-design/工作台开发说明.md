# 工作台

原熔炉保留内部 `furnace` ID，显示名称与功能改为工作台。沿用设备拖放、物品占格、窗口移动、跨天和交易流程。

- 初始一台工作台、三块赤铜矿、一份史莱姆粘液。
- 燃料区 4×8、材料区 8×8、产出区 4×8；矿石每件占 2×2。
- 每个工作台每晚消耗一份完整材料组合和一件燃料，制作一件成品。
- 剑为竖放三件；斧为竖放三件、顶部一侧再加一件；镐为五件 T 型。允许整体平移、斧形左右镜像。
- 赤铜、辉铁各三条基础配方。高级淬火剑：从上到下铁、铜、铁；高级淬火斧：顶部侧翼为铜，其他三件为铁。两者必须用古藤木。
- 无对应材质配方但形状正确时，产出同类赤铜装备。形状不成立、缺燃料、指定燃料不满足、输出空间不足均不消耗。
- 史莱姆粘液 60% / 古藤木 100%，对应基础装备耐久乘以 1 / 1.5。基础装备耐久20，淬火装备基础耐久24。成品满耐久生成，战斗扣除实例耐久。
- 输出区只能取出；关闭窗口保留内容，成品可以跨天积存。无自动补料或多配方识别。
- 图纸只可查看和翻页，不自动填入、不显示材料区引导。
- 矿石商人供应矿石与燃料；探索掉落也包含这些资源；旅剑士收购装备。
- 新增长装备出售时，结算先尝试旋转并为整批货物预留顾客格子；无法全部放下时不扣款、不转移物品。

## 主要文件

- `scripts/workbench_rules.gd`：形状、配方、燃料、统一预览判定。
- `scripts/trade_state.gd`：三区约束、隔天生产、实例耐久、交易装箱。
- `scripts/workbench_view.gd`：工作台外框与只读图纸。
- `scripts/shop.gd`：三区拖放、图纸弹窗、成品预览与商人供货。
- `assets/items/workbench/`：新增物品与炼药器、工作台 PNG 图标；工作台为 `4×4` 正方形，炼药器为 `3×4` 纵向矩形，两者均使用完全正面正交视角。
- 新增生成素材：`alembic-machine.png`、`workbench-machine.png`、`slime_mucus.png`、`ancient_wood.png` 与 `assets/exploration/ancient_tree.png`。

验证记录见 `docs/testing/工作台验证.md`。
